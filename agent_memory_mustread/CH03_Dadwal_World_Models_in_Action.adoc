== Adjustment equations/formulas

If you need to include Science, Technology, Engineering and Math (STEM)
expressions in your document, the AsciiDoc language supports embedding
math-mode macros from LaTeX notation as block or inline elements.
These elements act as passthroughs to preserve the expressions as entered.
The expressions are then passed on to the converter to be processed and
rendered for display using a STEM provider (MathJax).


=== Activating STEM support

To enable support for equations and formulas, simply set the stem attribute
in the document’s header.

|===
|
= <yourBookTitle>

:chapter: 3

:sectnums:

:figure-caption: Figure {chapter}.

:listing-caption: Listing {chapter}.

:table-caption: Table {chapter}.

:sectnumoffset: 2

:leveloffset: 1

:stem: latexmath

:stylesheet: css/manning.css
|
|===

=== Inline STEM content

For inline formulas, it is recommended to use the stem macro.

.Inline stem macro syntax
----
A basic latex math example stem:[C = \alpha + \beta Y^{\gamma} + \epsilon].
----

The result of the previously mentioned example is shown below.


A basic latex math example stem:[C = \alpha + \beta Y^{\gamma} + \epsilon].

===	Block STEM content

Block formulas are marked up by assigning the stem style to a delimited
passthrough block.

.Delimited stem block syntax
----
[stem]
++++
ATE=P(R=1|do(T=A)) - P(R=1|do(T=B))
++++
----

Again, the outcome of the above example is illustrated below.

[stem]
++++
ATE=P(R=1|do(T=A)) - P(R=1|do(T=B))
++++

Additionally, captions can be added to equation or formula blocks in the
same manner as they are for figures, listings, and tables.

.Delimited stem block syntax with caption
----
.A basic square root
[stem]
++++
\sqrt(4) = 2
++++
----

Once more, the result from the aforementioned example is presented below.

.A basic square root
[stem]
++++
\sqrt(4) = 2
++++

==== Newlines in LaTeX blocks

The standard LaTeX tools for equations may lack some flexibility, causing
overlapping or even trimming part of the equation when it’s too long.
Consider the following instance of an lengthy equation:


.Example of a long equation
----
[stem]
++++
P^{do(T=A)}(R=1|S=\mbox{Small}) P^{do(T=A)}(S=\mbox{Small}) + P^{do(T=A)}(R=1|L=\mbox{Large})P^{do(T=A)}(L=\mbox{Large}) = P^{do(T=A)}(R=1|S=\mbox{Small}, T=A) P^{do(T=A)}(S=\mbox{Small}) + P^{do(T=A)}(R=1|L=\mbox{Large}, T=A) P^{do(T=A)}(L=\mbox{Large})
++++
----

This next example displays the output generated by the latex code:

[stem]
++++
P^{do(T=A)}(R=1|S=\mbox{Small}) P^{do(T=A)}(S=\mbox{Small}) + P^{do(T=A)}(R=1|L=\mbox{Large})P^{do(T=A)}(L=\mbox{Large}) = P^{do(T=A)}(R=1|S=\mbox{Small}, T=A) P^{do(T=A)}(S=\mbox{Small}) + P^{do(T=A)}(R=1|L=\mbox{Large}, T=A) P^{do(T=A)}(L=\mbox{Large})
++++

These challenges can be overcome by employing the amsmath package.
This package offers various options for displaying equations, accommodating
different layouts suitable for your document. This is particularly useful
for very long equations or when including multiple equations in a single line.
Now, let’s explore how to split lines in the lengthy equation from the
earlier example:



.Example of a long equation with split lines
----
[stem]
\begin{equation}
\displaylines{ P^{do(T=A)}(R=1|S=\mbox{Small}) P^{do(T=A)}(S=\mbox{Small}) & \\ +  P^{do(T=A)}(R=1|L=\mbox{Large}) P^{do(T=A)}(L=\mbox{Large})&\\  = P^{do(T=A)}(R=1|S=\mbox{Small}, T=A) P^{do(T=A)}(S=\mbox{Small}) &\\  + P^{do(T=A)}(R=1|L=\mbox{Large}, T=A) P^{do(T=A)}(L=\mbox{Large}) }
\end{equation}
----

To do this, wrap your equation in the equation environment.
Within this environment, a double backslash acts as a line break.
Use the ampersand character (&) to align the equations vertically at
specific points.

[stem]
\begin{equation}
\displaylines{ P^{do(T=A)}(R=1|S=\mbox{Small}) P^{do(T=A)}(S=\mbox{Small}) & \\ +  P^{do(T=A)}(R=1|L=\mbox{Large}) P^{do(T=A)}(L=\mbox{Large})&\\  = P^{do(T=A)}(R=1|S=\mbox{Small}, T=A) P^{do(T=A)}(S=\mbox{Small}) &\\  + P^{do(T=A)}(R=1|L=\mbox{Large}, T=A) P^{do(T=A)}(L=\mbox{Large}) }
\end{equation}
