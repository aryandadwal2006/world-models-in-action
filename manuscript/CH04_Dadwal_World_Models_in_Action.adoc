[#unique_chapter4_title_ID,reftext={chapter},caption='{chapter}']
= Predicting in representation space

This chapter covers

* The JEPA objective and the transition from image to video prediction
* I-JEPA, V-JEPA, V-JEPA 2, and action-conditioned latent world models
* Collapse prevention, LeJEPA/SIGReg, and VISReg
* LeCun's proposed architecture for autonomous machine intelligence

A world model must retain information that helps an agent anticipate what can happen next, distinguish consequences that matter, and evaluate possible actions before committing to them. Chapter 2 framed this as a state-representation problem. Chapter 3 examined how an encoder can learn useful features without state labels. This chapter turns to a more direct training signal: predict the representation of something that is not currently available to the model.

Joint-Embedding Predictive Architectures (JEPAs) encode a context and predict a target in a shared representation space. The target may be a hidden region of an image, a masked portion of video, a future frame, or a text embedding associated with a visual context. The prediction is evaluated in feature space rather than by reconstructing every pixel. The design changes what the model is asked to explain: pixel reconstruction rewards texture, lighting and fine detail even when these are not relevant to the prediction of interest. A latent predictor can instead focus on aspects of the target that are predictable from the context under the selected representation.

The word _predictive_ needs care. In an image JEPA, a target region can be spatially withheld without being in the future. In a video JEPA, a target can be temporally later, spatially masked, or both. In an action-conditioned model, the predicted representation depends on a proposed action as well as the current observation. A JEPA is therefore not necessarily a temporal model, and a temporal JEPA is not automatically an action model.

The chapter proceeds in this order: the generic objective, image and video examples, distributional regularization, action-conditioned prediction, and finally the broader autonomous-agent proposal described by LeCun (2022). This progression teaches the predictive component before placing it inside a complete architecture.

*A world model is one component of an agent*

An autonomous agent requires at least four capabilities that should not be conflated: a representation of the current situation; a model of how it may change; a way to assess outcomes against goals or costs; and a mechanism for selecting and executing actions. Memory and task configuration affect all four. A representation-learning objective may improve the first two, but does not by itself provide a reliable planner, cost function, controller, or memory system.

LeCun’s _A Path Towards Autonomous Machine Intelligence_ proposes one way these pieces could fit together. It is a position paper, not a report of one fully implemented system. Its six top-level modules are Perception, World Model, Cost, Actor, Short-Term Memory, and Configurator. The Cost module contains an Intrinsic Cost component and a Trainable Critic; these are not additional top-level modules. We preview the module names here and reserve the detailed relationships for Section 4.3, after action-conditioned prediction.

A representation that ignores the position of a moving object may be adequate for scene classification but inadequate for predicting a collision. A representation that preserves object identity but not velocity may support recognition while failing to distinguish histories with different futures. The training target, mask and evaluation protocol determine which distinctions are encouraged.

*Evidence boundaries*

A mathematical result is valid under its stated assumptions. An empirical result belongs to the paper’s data, architecture, training recipe and evaluation protocol. An architectural proposal may guide research, but is not established merely because its diagram is coherent.

I-JEPA demonstrates image representation learning with latent prediction. V-JEPA demonstrates feature prediction as a video pretraining objective. V-JEPA 2 separates action-free video pretraining from a later action-conditioned model trained with robot trajectories. LeJEPA develops a theory and objective for regularized embeddings. VISReg proposes a different regularizer separating scale and shape. These are related contributions, not interchangeable implementations of one fixed model.

Chapter 3 has already introduced contrastive learning, bootstrap methods, redundancy reduction, VICReg, masked reconstruction and collapse. We use those ideas as context rather than repeating their full derivations. The focus here is the predictive target, the encoder-predictor system, and the distributional constraints placed on its representation.

[#unique_section_ch4_001_why_predict_in_latent_space]
== Why predict in latent space?

A predictive model can estimate an observation, a distribution over observations, or a representation of an observation. These choices define different learning problems. A JEPA takes the third route: encode the context and target, then train a predictor to make the context representation agree with the target representation.

Let an observation be latexmath:[$x$], with representation latexmath:[$z=f_\theta\(x$]). The objective is not to reconstruct latexmath:[$x$] from latexmath:[$z$]. Instead, use an available context latexmath:[$x_c$] to predict a target feature latexmath:[$z_t$] extracted from a withheld or later portion of the data. The loss measures the difference between the predicted and target embeddings.

This can be useful when the observation contains details that are expensive to model and irrelevant to the prediction of interest. A video frame contains texture, sensor noise, shadows and fine-grained appearance. Some details matter for physical interaction, but not all need to be predicted at every step. A model can potentially devote more capacity to object arrangement, motion and other structure by predicting in a feature space rather than reconstructing all pixels.

The qualification is important. The latent space does not become semantic merely because the predictor operates in it. The target encoder, mask distribution, temporal sampling, representation dimension, objective and regularizer determine what the model is encouraged to preserve. Latent prediction changes the learning target; it does not certify sufficiency for every downstream problem.

[#unique_section_ch4_002_prediction_is_not_reconstruction]
=== Prediction is not reconstruction

Suppose a context is compatible with several future frames. Pixel-level regression can average incompatible appearances. Latent prediction can focus on a target feature that captures predictable structure, leaving unpredictable detail outside the target. This may make learning more tractable, but it raises a design question: which aspects of the future count as predictable and important?

Under squared error, the optimal predictor of a target feature latexmath:[$Z_t$] given context latexmath:[$C$] is its conditional mean:

[latexmath]
++++
\[
g^*(C)=\mathbb{E}[Z_t\mid C].
\]
++++
For a candidate prediction (hlatexmath:[$C$]), add and subtract the conditional mean (mulatexmath:[$C$]):

[latexmath]
++++
\[
\begin{aligned}
\mathbb{E}[\|Z_t-h(C)\|^2\mid C]
&=\mathbb{E}[\|Z_t-\mu(C)\|^2\mid C]\\
&\quad+\|\mu(C)-h(C)\|^2.
\end{aligned}
\]
++++
The cross term vanishes because latexmath:[$\mathbb{E}[Z_t-\mu\(C$]C]=0). The first term does not depend on latexmath:[$h$], so the conditional mean minimizes expected squared error, assuming a finite conditional second moment.

This identity explains an important limitation. If the target distribution is multimodal, the conditional mean can lie between plausible futures. A deterministic predictor trained with a pointwise squared loss may represent an average rather than preserve the alternatives. A JEPA objective alone does not solve multimodal prediction or calibrated uncertainty.

[#unique_section_ch4_003_the_target_determines_the_question]
=== The target determines the question

A target can be selected spatially, temporally, action-conditionally or across modalities.

* A spatial target asks what can be inferred about a hidden region from visible context.
* A temporal target asks what future content is predictable from earlier observations.
* An action-conditioned target asks what future representation is predicted after a particular action or action sequence.
* A cross-modal target asks which representation in one modality is compatible with a context from another modality.

These targets are not equivalent. Predicting a masked patch in the same frame does not test whether the model predicts motion. Predicting future video without actions does not identify the consequences of a candidate control input. Predicting text embeddings from an image does not by itself provide a physical dynamics model.

The mask is part of the task definition. A target too close to visible context may admit a shortcut based on local texture. A target too distant or too large may be difficult to infer. A context that hides too much may remove information necessary for prediction. Success depends on the relation between what is visible and what is withheld.

[#unique_section_ch4_004_the_representation_contract_remains_in_force]
=== The representation contract remains in force

Chapter 2 defined a useful state in terms of the information needed for downstream prediction and control. A JEPA offers a way to learn such a representation, but its pretraining loss is still a proxy objective. We must ask whether the representation retains distinctions that affect relevant futures and whether downstream probes or tasks can access them.

A frozen linear probe measures information accessible to a linear readout under a chosen protocol. A nonlinear probe tests a more flexible readout. A dense prediction task tests spatial structure. A planning experiment evaluates a model together with a planner, cost, action parameterization and environment. None establishes universal predictive sufficiency.

[#unique_section_ch4_005_the_joint_embedding_predictive_objective]
== The joint-embedding predictive objective

A canonical JEPA contains a context encoder, a target encoder and a predictor. The context encoder processes the part of the observation that the model is allowed to see. The target encoder produces features for the withheld or later target. The predictor maps context features, together with information about the requested target, to an estimate of those target features.

Let latexmath:[$x_c$] denote the context and latexmath:[$x_t$] the target. Their embeddings are

[latexmath]
++++
\[
z_c=f_\theta(x_c),\qquad z_t=f_{\bar\theta}(x_t).
\]
++++
A predictor with parameters latexmath:[$\phi$] produces

[latexmath]
++++
\[
\hat z_t=g_\phi(z_c,q),
\]
++++
where latexmath:[$q$] identifies the target location, time or query. A useful abstract objective is

[latexmath]
++++
\[
\mathcal L_{pred}
=\mathbb E_{(x_c,x_t,q)}
\left[d\left(g_\phi(f_\theta(x_c),q),
\operatorname{sg}(f_{\bar\theta}(x_t))\right)\right].
\]
++++
Here latexmath:[$d$] is a feature-space discrepancy and latexmath:[$\operatorname{sg}$] denotes stop-gradient on the target branch. This is a generic schematic, not a universal definition of every JEPA implementation.

In common teacher-student designs, the target parameters are updated as an exponential moving average:

[latexmath]
++++
\[
\bar\theta\leftarrow\tau\bar\theta+(1-\tau)\theta,
\]
++++
where latexmath:[$\tau$] is close to one. EMA provides a slowly changing target. It is a common stabilizing choice, not a requirement of the JEPA family. LeJEPA, for example, uses a different multi-view design without an EMA teacher.

[#unique_section_ch4_006_the_query_is_part_of_the_prediction]
=== The query is part of the prediction

The predictor needs to know which target it should estimate. For an image, this may be a spatial position associated with a masked block. For video, it may include spatial and temporal coordinates. For action-conditioned prediction, actions and relevant robot state are additional inputs.

A pooled context vector alone may not specify whether the model should estimate a target on the left or right of an image, or at which time step. A query supplies this information. Transformer implementations often combine learned mask or query tokens with positional encodings.

The predictor is not simply a decoder with a pixel loss. Its output is an embedding under the target encoder’s representation convention. It may itself be a substantial transformer, but it is trained to predict features rather than observations.

[#unique_section_ch4_007_what_makes_the_embedding_spaces_joint]
=== What makes the embedding spaces joint?

The context and target embeddings must be comparable. They may be produced by separate networks with related parameterization, or by a shared encoder applied to different inputs. In teacher-student designs, the target network changes more slowly than the context network, providing a relatively stable reference.

The branches receive different information. The context encoder cannot see target content, while the target encoder may process the full observation or the unmasked target crop. The asymmetry makes prediction non-trivial: the model must infer target features from context rather than copy them from the input.

The target-update rule matters. If targets move too quickly, the predictor chases a changing representation. If targets move too slowly, they can become stale. EMA schedules, normalization, predictor depth and optimization are implementation decisions to be checked against the method being discussed.

[#unique_section_ch4_008_the_loss_does_not_specify_the_whole_method]
=== The loss does not specify the whole method

A complete recipe must specify how contexts and targets are sampled; whether targets are blocks, frames, tokens or modalities; how the target encoder is updated; how many targets are predicted from one context; how target positions are represented; how the loss is normalized and aggregated; how collapse is discouraged; and which representation is evaluated downstream.

A simple loss can hide substantial inductive bias in the sampling procedure. I-JEPA demonstrates this with its spatial block-mask design. V-JEPA extends the target to video. V-JEPA 2 adds action-conditioned prediction only after action-free pretraining. LeJEPA changes the regularization strategy. These distinctions are central to the methods.

[#unique_section_ch4_009_collapse_and_regularization]
=== Collapse and regularization

A constant representation can satisfy some prediction objectives without retaining useful variation. Architectural asymmetry, target networks, stop-gradient, normalization and explicit regularizers are different responses to this issue. Chapter 3 already developed the main anti-collapse families, so this chapter only needs a brief handoff.

For a batch of embeddings latexmath:[$Z\in\mathbb R^{B\times D}$], a variance constraint discourages individual dimensions from becoming constant. A covariance penalty discourages redundant linear correlations. These constraints are useful but do not determine the full joint distribution: zero covariance does not imply independence or Gaussianity.

LeJEPA uses projected distributional tests to compare embeddings with an isotropic Gaussian target. VISReg instead combines explicit scale control, a sliced-Wasserstein shape term and centering. Their statistical targets and gradient paths differ, so they need separate treatments.

[#unique_section_ch4_010_i_jepa_predicting_hidden_regions_of_an_image]
== I-JEPA: predicting hidden regions of an image

I-JEPA is the image-based JEPA introduced by Assran and colleagues (2023). It predicts representations of several target blocks from a single context block in the same image. The target is not a patch of pixels reconstructed by a decoder; it is a feature representation produced by a target encoder.

The image is divided into patch tokens by a Vision Transformer. A context mask selects a spatially distributed subset of patches. The context encoder processes those visible tokens. Multiple target masks select larger blocks elsewhere in the image. The target encoder processes the corresponding target regions and supplies the reference features. The predictor receives the context representation and a query for each target position, then predicts the target features.

The target encoder is initialized from the context encoder and updated by an exponential moving average. Its outputs are treated as targets rather than as a branch directly optimized by the prediction loss. The predictor estimates multiple target blocks from the same context. Since the context is spatially distributed, it can contain evidence about objects and scene structure beyond a single contiguous crop.

[#unique_section_ch4_011_why_the_mask_matters]
=== Why the mask matters

If target blocks are too small, the model may exploit local continuity or texture. If the visible context is too narrow or poorly positioned, important evidence may be hidden. If the targets are too large, they may contain too much unpredictable content. The I-JEPA paper emphasizes two connected choices: target blocks should be sufficiently large to require semantic context, and the context should be spatially distributed and informative.

The model does not receive a target image patch through a pixel decoder. It receives target embeddings from the target encoder. This makes that encoder’s representation central to the method. The target may ignore variation that does not affect its features, but it can also omit information if its representation is insensitive to it.

[#unique_section_ch4_012_what_the_experiments_establish]
=== What the experiments establish

The CVPR 2023 paper reports a ViT-Huge/14 trained on ImageNet using 16 A100 GPUs in under 72 hours. The reported evaluation includes classification, object counting and depth prediction. This supports the claim that a non-generative feature-prediction objective can learn useful image representations under the paper’s setup.

It does not establish physical dynamics. A single image does not identify velocity without temporal information, and the method does not learn how an action changes a scene. I-JEPA is an image representation learner and an example of spatial latent prediction, not an action-conditioned world model.

[#unique_section_ch4_013_v_jepa_predicting_features_from_video]
== V-JEPA: predicting features from video

V-JEPA extends feature prediction from images to video. In the original work, Bardes and colleagues (2024) train visual representations with a feature-prediction objective on video, without a pretrained image encoder, text, negative examples, pixel reconstruction or other external supervision. The central change from I-JEPA is the temporal structure of the input and target.

A clip can be represented as a grid of spatiotemporal tokens. The context contains visible portions of the clip, while the target contains masked spatiotemporal regions. A context encoder processes visible tokens. A target encoder produces features for hidden regions. A predictor estimates those features using context information and the target’s spatial and temporal location.

An individual image contains appearance and spatial arrangement at one instant. A sequence contains change. An object at one location may be moving, stationary or about to be occluded. These possibilities can look similar in one frame but imply different future observations. Video prediction can therefore produce features sensitive to appearance and motion.

The target is not necessarily a later frame. V-JEPA’s masked spatiotemporal prediction objective withholds regions across space and time. The model predicts features for those regions rather than reconstructing every pixel. The target representation defines the level of abstraction at which prediction is rewarded.

[#unique_section_ch4_014_the_original_empirical_evidence]
=== The original empirical evidence

The original V-JEPA paper reports training on approximately two million videos collected from public datasets. Its largest model, a ViT-H/16 trained only on videos, obtains 81.9% on Kinetics-400, 72.2% on Something-Something-v2 and 77.9% on ImageNet-1K with a frozen backbone under the paper’s protocols. These results show transfer to both motion-centric and appearance-centric evaluations.

A frozen-backbone score measures feature quality under a particular readout, not the ability to plan an action sequence. V-JEPA studies representation learning. It does not automatically infer the causal effect of a robot command: passive video records observed motion but does not necessarily expose the controls that produced it.

Schematically, passive video prediction uses context such as latexmath:[$z_{\leq t}$], whereas action-conditioned prediction also receives latexmath:[$a_t$]:

[latexmath]
++++
\[
p(z_{t+1}\mid z_{\leq t})\quad\text{versus}\quad
p(z_{t+1}\mid z_{\leq t},a_t).
\]
++++
These expressions identify the information difference; they are not literal definitions of the V-JEPA or V-JEPA 2 objectives.

[#unique_section_ch4_015_v_jepa_2_and_v_jepa_2_1]
== V-JEPA 2 and V-JEPA 2.1

V-JEPA 2 makes the transition from video representation learning toward world modeling more explicit. It separates large-scale action-free pretraining from an action-conditioned post-training stage. The pretrained encoder learns visual structure from images and videos, while the action-conditioned predictor is trained with robot trajectories to model how future visual states depend on actions.

The original V-JEPA 2 paper reports pretraining on a video and image dataset comprising more than one million hours of internet video. It describes 22 million samples combining video and images. The pretrained model is action-free: it learns from visual observations without requiring action labels for every sequence.

[#unique_section_ch4_016_the_action_free_stage]
=== The action-free stage

The encoder and predictor are pretrained with masked latent feature prediction. As in earlier JEPAs, the model is not trained to reconstruct RGB pixels. The paper reports 77.3 top-1 accuracy on Something-Something-v2 for motion understanding and 39.7 recall-at-five on EPIC-KITCHENS-100 for human action anticipation. It also reports video question-answering evaluations after aligning the visual encoder with a language model. Those VQA scores should not be conflated with the planning evaluation.

[#unique_section_ch4_017_v_jepa_2_ac_adding_actions]
=== V-JEPA 2-AC: adding actions

After pretraining, the authors freeze the visual encoder and learn a new action-conditioned predictor. It estimates future frame representations from past visual features, robot actions and end-effector states. The paper uses an autoregressive feature-prediction objective with a teacher-forced prediction loss and an additional rollout loss.

A schematic model is

[latexmath]
++++
\[
\hat z_{t+1}=g_\phi(z_{\leq t},a_{\leq t},s_{\leq t}),
\]
++++
where latexmath:[$z$] denotes visual features, latexmath:[$a$] actions and (s) end-effector state. The actual model uses sequences and specific action/state encodings. The key point is that the predictor receives variables describing the intervention, not only the observed video.

At inference, the system receives a goal image and plans an action sequence expected to reach a matching visual state. The authors report deployment on Franka arms in two laboratories for reaching, grasping and pick-and-place tasks. They describe this as zero-shot with respect to the test environments: no data were collected from those deployment environments, and no task-specific training or reward was required for the evaluated tasks. The system did use robot data: the action-conditioned stage used less than 62 hours of unlabeled robot video from the DROID dataset.

``Zero-shot'' therefore describes the relation between training and evaluated environments or tasks. It should not be read as ``no interaction data,'' ``no training,'' or ``no planning.''

[#unique_section_ch4_018_planning_in_representation_space]
=== Planning in representation space

A planner can search over candidate action sequences by evaluating the future representations they imply. A goal image is encoded into a target representation. Candidate actions are rolled through the action-conditioned model. The predicted representation is compared with the goal representation and the action sequence is updated.

A schematic objective is

[latexmath]
++++
\[
\hat{\mathbf a}_{1:H}
=\arg\min_{\mathbf a_{1:H}}
d(\hat z_{t+H}(\mathbf a_{1:H}),z_{goal})
+\lambda R(\mathbf a_{1:H}),
\]
++++
where (d) measures agreement with a goal representation and (R) can express an action or feasibility penalty. This explains the logic of latent-space planning; it is not a verbatim statement of every term in the V-JEPA 2-AC implementation.

A predicted goal match can be plausible in feature space while the physical state is unsafe or infeasible. Planning quality depends on the representation, action model, horizon, cost, action constraints and feedback loop. Results from two laboratories are evidence under the reported setup, not proof of general-purpose physical reasoning.

[#unique_section_ch4_019_v_jepa_2_1_is_a_different_extension]
=== V-JEPA 2.1 is a different extension

V-JEPA 2.1 focuses on dense visual features rather than introducing the action-conditioning stage. Its paper describes four components: a dense predictive loss supervising visible and masked tokens, deep self-supervision across intermediate encoder layers, multimodal tokenizers for image and video inputs, and model/data scaling. The stated motivation is to improve spatial and temporal structure in feature maps while retaining global scene understanding.

V-JEPA 2.1 should not be described as synonymous with V-JEPA 2-AC. The former is a dense representation-learning recipe. The latter is the action-conditioned world model introduced in the V-JEPA 2 paper. The official repository maintains code for V-JEPA 2, 2-AC and 2.1, but their training objectives and system roles differ.

[#unique_section_ch4_020_from_collapse_prevention_to_distributional_r]
== From collapse prevention to distributional regularization

A predictive loss does not automatically determine a useful embedding geometry. If every input maps to the same vector, a representation can contain no information about the input. Some architectures avoid this solution through asymmetry and optimization dynamics; other methods impose explicit statistical constraints on the batch of embeddings.

Chapter 3 has already explained the mechanisms used by contrastive, bootstrap, self-distillation and redundancy-reduction methods. This section only establishes the transition needed for LeJEPA and VISReg.

[#unique_section_ch4_021_three_different_questions]
=== Three different questions

It is useful to separate three properties of an embedding distribution:

[arabic]
. *Non-collapse:* do different inputs produce a non-constant representation?
. *Redundancy:* do feature dimensions carry strongly overlapping linear information?
. *Distributional shape:* what is the joint distribution of the embedding vectors, beyond their coordinate-wise variance and pairwise covariance?

VICReg addresses the first two explicitly. Its variance term maintains a minimum standard deviation for each coordinate, while its covariance term penalizes off-diagonal covariance. The method also contains an invariance term that brings representations of different views of the same sample together. These components are not interchangeable: variance prevents individual dimensions from becoming constant; covariance discourages linear redundancy; invariance defines which views should agree.

Barlow Twins instead uses the cross-correlation matrix between two batches of embeddings and pushes it toward the identity. Its diagonal terms align matching coordinates across views, while off-diagonal terms penalize cross-coordinate redundancy. This is not the same mechanism as VICReg’s within-view variance floor or EMA teacher updates. Both methods belong to the broader family of explicit statistical regularization, but their statistics and optimization behaviour differ.

[#unique_section_ch4_022_why_second_order_statistics_leave_a_gap]
=== Why second-order statistics leave a gap

Mean and covariance do not specify an arbitrary multivariate distribution. Two distributions can share the same mean and identity covariance while differing in skewness, tail behaviour, multimodality or support. Uncorrelated coordinates need not be independent, and uncorrelated features are not necessarily Gaussian.

This observation motivates distributional regularizers. Instead of constraining only a few moments, they compare the embedding distribution with a target distribution using a statistic that can detect a broader range of differences.

That additional target is also a stronger modeling assumption. If the regularizer asks embeddings to follow an isotropic Gaussian, it is not merely asking that the model avoid collapse. It is prescribing a shape. Whether that shape is useful depends on the downstream criterion and the training setup. LeJEPA motivates its Gaussian target through a particular downstream prediction-risk analysis. VISReg adopts a Gaussian shape target as part of a scale-and-shape regularizer. Neither should be described as proving that Gaussian embeddings are universally ideal for every representation task.

[#unique_section_ch4_023_the_handoff_to_sigreg_and_visreg]
=== The handoff to SIGReg and VISReg

LeJEPA’s SIGReg sketches one-dimensional distributional tests along sampled directions and compares each projected feature distribution with a standard normal. Its statistic is based on empirical characteristic functions. VISReg uses a different sketch: it sorts projected samples and compares them with Gaussian quantiles using a one-dimensional Wasserstein objective. It also separates the scale correction from the shape calculation.

Both methods rely on projections, but their losses, gradient paths and finite-sample behaviour are not the same. The next two sections derive them independently.

The point is that decorrelation constrains second-order statistics but does not determine the full joint density.

[#unique_section_ch4_024_lejepa_and_sketched_isotropic_gaussian_regul]
== LeJEPA and Sketched Isotropic Gaussian Regularization

LeJEPA, introduced by Balestriero and LeCun (2025), combines a predictive multi-view objective with a distributional regularizer called Sketched Isotropic Gaussian Regularization (SIGReg). Its central proposal is that, under the downstream prediction-risk framework studied in the paper, an isotropic Gaussian embedding distribution is optimal. SIGReg then provides a practical way to encourage that distribution without evaluating a high-dimensional density directly.

The theorem and the implementation answer different questions. The theory studies what embedding distribution minimizes a specified downstream risk. SIGReg is a stochastic numerical objective that encourages the learned embeddings to approach that target. The latter does not turn a finite minibatch into a certificate that the population embedding distribution is exactly Gaussian.

[#unique_section_ch4_025_the_gaussian_target_and_the_scope_of_the_the]
=== The Gaussian target and the scope of the theory

Let an encoder produce an embedding latexmath:[$Z=f_\theta(X)\in\mathbb R^d$]. The paper studies downstream prediction from frozen representations. In its linear setting, a probe fits a regularized least-squares estimator. The analysis compares embedding geometries under matched representational capacity, including a comparison between isotropic and anisotropic covariance structures. Anisotropy can increase the worst-case bias of a regularized linear estimator and the variance of an unregularized estimator.

The paper also analyzes nonlinear probes, including radius-based nearest-neighbour regression and kernel regression. Under the regularity conditions and fixed-variance constraints stated in the paper, the analysis identifies the isotropic Gaussian as the unique minimizing distribution for the risk terms considered. The Gaussian’s score function and the associated Fisher-information functional are central to the nonlinear analysis.

This is a meaningful theoretical result, but its scope must remain explicit. It concerns the downstream estimator families, risk criterion, regularity assumptions and fixed-scale constraints used in the paper. It is not a theorem that Gaussian latents are optimal for every conceivable task, every control problem, every conditional transition model or every data distribution. A task may need discrete modes, constraints, multimodality or structured variables that a simple isotropic Gaussian prior does not express on its own.

The useful design principle is therefore conditional: if the goal is to support the class of downstream estimators and risk assumptions analyzed in LeJEPA, isotropic Gaussian embeddings provide the paper’s optimal target. The chapter should not turn that statement into an unrestricted claim about semantic quality or physical sufficiency.

[#unique_section_ch4_026_from_a_multivariate_test_to_one_dimensional_]
=== From a multivariate test to one-dimensional projections

Suppose the empirical embedding distribution is latexmath:[$P_\theta$] and the desired target is latexmath:[$Q=\mathcal N(0,I_d)$]. Directly testing whether a high-dimensional sample comes from latexmath:[$Q$] can be computationally expensive. SIGReg instead projects the embeddings onto unit directions.

For a unit vector latexmath:[$a\in\mathbb S^{d-1}$], the scalar projection is

[latexmath]
++++
\[
U=a^\top Z.
\]
++++
If latexmath:[$Z\sim\mathcal N(0,I_d)$], then latexmath:[$U\sim\mathcal N(0,1)$] for every unit direction latexmath:[$a$]. A directional test can therefore compare the projected sample with a univariate standard-normal target.

The Cramér-Wold theorem supplies the identification principle: a multivariate probability distribution is uniquely determined by the family of all its one-dimensional projected distributions. If every one-dimensional projection of latexmath:[$P$] matches the corresponding projection of latexmath:[$Q$], the two distributions are equal. That is an all-directions statement.

SIGReg uses a finite collection of directions at each training step. It resamples directions during training, so the optimizer sees a changing set of one-dimensional views over time. This stochastic sketch is computationally practical, but a finite minibatch and a finite number of directions do not prove exact equality of the population distributions. The paper’s analysis also studies how embedding smoothness and repeated random directions affect how strongly a finite sketch constrains the full distribution.

[#unique_section_ch4_027_characteristic_functions]
=== Characteristic functions

For a scalar random variable latexmath:[$U$], its characteristic function is

[latexmath]
++++
\[
\varphi_U(t)=\mathbb E[e^{itU}].
\]
++++
For a standard normal random variable,

[latexmath]
++++
\[
\varphi_{\mathcal N(0,1)}(t)=e^{-t^2/2}.
\]
++++
Given projected samples latexmath:[$u_1,\ldots,u_B$], the empirical characteristic function is

[latexmath]
++++
\[
\widehat\varphi_B(t)=\frac{1}{B}\sum_{b=1}^{B}e^{itu_b}.
\]
++++

The empirical characteristic function is a finite average of complex exponentials. It is differentiable with respect to the samples and can be aggregated across distributed workers using sum-reduction operations. Unlike high-order moments, the complex exponentials remain bounded as the magnitude of the input grows.

[#unique_section_ch4_028_the_epps_pulley_statistic]
=== The Epps-Pulley statistic

LeJEPA uses an Epps-Pulley-style statistic to compare an empirical characteristic function with the target characteristic function:

[latexmath]
++++
\[
T_{EP}(u_{1:B})
=
B\int_{-\infty}^{\infty}
\left|\widehat\varphi_B(t)-\varphi_0(t)\right|^2
w(t)\,dt,
\]
++++
where latexmath:[$\varphi_0\(t$]=e^\{-t^2/2}) and latexmath:[$w\(t$]) is a weighting function, typically Gaussian. The weighting controls how discrepancies across frequencies contribute to the statistic.

This formula is the population-integral description. A practical implementation approximates the integral by numerical quadrature over a finite set of frequencies. The LeJEPA paper reports a trapezoidal approximation using a small number of integration knots, and its experiments ablate the range and number of points. It also discusses the finite-minibatch bias in the empirical statistic, which vanishes at an latexmath:[$\mathcal O(1/B)$] rate in the paper’s analysis.

SIGReg samples directions latexmath:[$a_1,\ldots,a_M$], computes the projected samples latexmath:[$a_m^\top z_b$], evaluates a univariate statistic for each direction, and aggregates the directional losses. For the training objective, the paper averages directional statistics rather than taking their maximum. The maximum appears in the testing-theoretic construction; averaging is chosen in the optimization objective to avoid sparse gradients concentrated on only the worst direction.

A schematic training loss is

[latexmath]
++++
\[
\mathcal L_{SIGReg}(Z)
=
\frac{1}{M}\sum_{m=1}^{M}
T_{EP}\big(a_m^\top z_1,\ldots,a_m^\top z_B\big).
\]
++++
The precise quadrature range, frequency weights, direction sampling, normalization and distributed aggregation are implementation details and should be read from the cited paper version and official code, not inferred from this schematic.

[#unique_section_ch4_029_the_lejepa_objective]
=== The LeJEPA objective

LeJEPA uses multiple global and local views of an observation. Let latexmath:[$z_{n,v}$] denote the embedding for sample latexmath:[$n$] and view latexmath:[$v$]. Let the first latexmath:[$V_g$] views be global, and let latexmath:[$V=V_g+V_l$] include all global and local views. The paper’s prediction term encourages each view to agree with the mean embedding of the global views:

[latexmath]
++++
\[
\mu_n=\frac{1}{V_g}\sum_{v=1}^{V_g}z_{n,v},
\qquad
\mathcal L_{pred}
=
\frac{1}{V}\sum_{v=1}^{V}
\|\mu_n-z_{n,v}\|_2^2,
\]
++++
averaged across samples. SIGReg is applied to the embedding sets for the views. The total objective is

[latexmath]
++++
\[
\mathcal L_{LeJEPA}
=
(1-\lambda)\mathcal L_{pred}
+
\lambda\mathcal L_{SIGReg}.
\]
++++

This formulation differs from the common EMA teacher-predictor JEPA. In the specified LeJEPA recipe, the model does not require an EMA teacher, stop-gradient target branch or a predictor network. It uses a prediction term over multiple views and an explicit distributional regularizer. It should not be generalized into a claim that no JEPA requires target stabilization or that every target-prediction architecture can remove its predictor without changing the task.

[#unique_section_ch4_030_why_characteristic_functions]
=== Why characteristic functions?

The paper compares moment-based, cumulative-distribution and characteristic-function tests. Moment tests can be sensitive to outliers and require higher moments to distinguish more distributional structure. CDF-based tests often involve sorting or order statistics, creating synchronization and differentiability difficulties in distributed gradient training. The characteristic function is differentiable and naturally amenable to averaging across data-parallel workers.

The numerical quadrature is an approximation. The Epps-Pulley statistic is the statistical object; the particular grid, frequency range and finite batch define its practical estimate. LeJEPA reports linear memory and computational complexity in minibatch size for its implementation, while the full cost also depends on embedding dimension, number of projected directions and quadrature points. Complexity statements must state which quantities are held fixed.

[#unique_section_ch4_031_what_sigreg_does_and_does_not_establish]
=== What SIGReg does and does not establish

SIGReg provides a differentiable distributional signal that goes beyond mean and covariance matching. It samples one-dimensional projections and compares their empirical characteristic functions with a normal target. The repeated sampling of directions is central to its sketching interpretation.

It does not establish exact Gaussianity from one training step. It does not guarantee that the representation is a sufficient statistic for every environment. It does not ensure calibrated uncertainty or action-conditioned dynamics. It does not prove that distances in latent space correspond to physical distances. And the theorem’s downstream optimum should not be read outside its assumptions.

The LeJEPA paper reports stability across different architectures, datasets and hyperparameters, including scaling to very large models. It also reports that training loss correlates with linear-probe performance in the tested ImageNet setup. These are empirical findings of that paper, not a universal guarantee that training loss always replaces downstream evaluation.

The next section examines a related but distinct approach. VISReg retains a scale constraint and replaces the characteristic-function discrepancy with a sliced-Wasserstein shape objective.

[#unique_section_ch4_032_visreg_separating_scale_and_shape]
== VISReg: separating scale and shape

VISReg (Wu, Balestriero and Levine, 2026) proposes Variance-Invariance-Sketching Regularization for JEPA training. It is motivated by a distinction between the magnitude of a representation and the shape of its distribution. The method retains an explicit scale penalty and uses a sliced-Wasserstein objective to compare normalized projected embeddings with a Gaussian target.

The authors’ motivation is that VICReg’s covariance term controls second-order relationships but not the full distributional shape, while SIGReg’s characteristic-function sketch can provide weak gradients near collapse in the tested setup. VISReg responds by separating scale and shape rather than asking one distributional discrepancy to perform both roles. These are the paper’s motivation and empirical claims, not a proof that VISReg dominates every other regularizer on every model or dataset.

[#unique_section_ch4_033_center_scale_and_shape]
=== Center, scale and shape

Let latexmath:[$Z\in\mathbb R^{B\times D}$] be a batch of embeddings, with latexmath:[$B$] samples and latexmath:[$D$] feature dimensions. Define the batch mean

[latexmath]
++++
\[
\mu=\frac{1}{B}\sum_{b=1}^{B}z_b,
\qquad
Z_c=Z-\mu.
\]
++++
Let latexmath:[$\sigma_j\(Z_c$]) be the standard deviation of coordinate latexmath:[$j$]. VISReg defines a scale term

[latexmath]
++++
\[
\mathcal L_{scale}
=
\frac{1}{D}\sum_{j=1}^{D}
\left(1-\sigma_j(Z_c)\right)^2.
\]
++++
This term encourages unit standard deviation per coordinate. It supplies a direct penalty when the embedding dimensions shrink toward zero.

The shape term first normalizes the centered embeddings by their coordinate-wise standard deviations. The standard deviation is detached from the gradient path:

[latexmath]
++++
\[
\widetilde Z
=
\frac{Z_c}{\operatorname{sg}(\sigma(Z_c))+\epsilon}.
\]
++++
Here latexmath:[$\operatorname{sg}$] is stop-gradient and the division is coordinate-wise. The small latexmath:[$\epsilon$] protects the normalization from numerical division by zero. The normalization is intended to remove scale from the shape comparison, so that the shape loss is not asked to restore the overall feature magnitude.

[#unique_section_ch4_034_sliced_wasserstein_shape_objective]
=== Sliced-Wasserstein shape objective

For a unit vector latexmath:[$w_k\in\mathbb S^{D-1}$], project the normalized embeddings:

[latexmath]
++++
\[
u_k=\widetilde Z w_k.
\]
++++
The projected samples form a one-dimensional empirical distribution. If the target is a standard isotropic Gaussian in the embedding space, each unit-direction projection has a standard-normal target distribution.

For equally weighted empirical samples with equal cardinality, the one-dimensional quadratic Wasserstein distance can be computed by sorting the samples and matching corresponding order statistics. Let latexmath:[$q_B$] denote the vector of target standard-normal quantiles under the paper’s finite-sample convention. The shape loss is

[latexmath]
++++
\[
\mathcal L_{shape}
=
\frac{1}{K}\sum_{k=1}^{K}
\left\|
\operatorname{sort}(\widetilde Z w_k)-q_B
\right\|_2^2.
\]
++++
The latexmath:[$K$] directions are sampled and normalized. Sorting gives the one-dimensional optimal matching for equal sample weights and equal sample counts. Different weighting or quantile conventions would change the exact formula, so the figure and prose should not hide this assumption.

The Cramér-Wold theorem again provides the population-level intuition: all one-dimensional projections determine the multivariate distribution. VISReg uses a finite set of slices, so the training loss is a stochastic sketch. The number of directions latexmath:[$K$] affects the quality of the approximation and the computation. It is not correct to say that finite latexmath:[$K$] guarantees exact distributional equality.

[#unique_section_ch4_035_centering_and_total_objective]
=== Centering and total objective

VISReg adds a centering term

[latexmath]
++++
\[
\mathcal L_{center}=\|\mu\|_2^2.
\]
++++
The regularizer combines the three parts, with weights made explicit:

[latexmath]
++++
\[
\mathcal L_{reg}
=
\lambda_s\mathcal L_{scale}
+
\lambda_h\mathcal L_{shape}
+
\lambda_c\mathcal L_{center}.
\]
++++
The full objective combines this regularization with a predictive invariance term:

[latexmath]
++++
\[
\mathcal L_{VISReg}
=
(1-\lambda)\mathcal L_{pred}
+
\lambda\mathcal L_{reg}.
\]
++++
The exact normalization, loss weights, view-averaging convention and standard-deviation implementation should follow the paper’s version rather than a notationally simplified equation. In particular, the symbols latexmath:[$K$] and latexmath:[$D$] have different roles: latexmath:[$D$] is the embedding dimension, while latexmath:[$K$] is the number of random slices.

[#unique_section_ch4_036_why_separate_scale_from_shape]
=== Why separate scale from shape?

The scale loss acts directly on the standard deviation. For one coordinate, its derivative is

[latexmath]
++++
\[
\frac{\partial}{\partial\sigma_j}
\frac{1}{D}(1-\sigma_j)^2
=
-\frac{2}{D}(1-\sigma_j).
\]
++++
As latexmath:[$\sigma_j\to0$], this derivative approaches latexmath:[$-2/D$], rather than zero. This demonstrates a non-vanishing derivative with respect to the scalar standard-deviation statistic at collapse.

It is important not to overstate what this derivative proves. It is not, by itself, a lower bound on the gradient with respect to every encoder parameter. The chain from parameters to batch statistics can be affected by the architecture, normalization, saturation, finite precision and data batch. The paper’s gradient comparisons are experiments under a stated simulation and training setup; the displayed scalar derivative is an analytic explanation of the scale term, not a universal theorem of recovery for arbitrary networks.

The detached standard deviation in the shape normalization prevents the shape loss from sending gradients through the scale denominator. This separates the correction of feature magnitude from the distributional shape comparison. The stop-gradient here has a different role from the EMA target asymmetry in I-JEPA or V-JEPA. Do not conflate all stop-gradient operations into one mechanism.

[#unique_section_ch4_037_computational_considerations]
=== Computational considerations

The main work includes projecting a batch into latexmath:[$K$] directions and sorting latexmath:[$B$] values along each direction. A schematic cost is

[latexmath]
++++
\[
\mathcal O(BDK)+\mathcal O(KB\log B).
\]
++++
The first term is the projection work; the second is the per-direction sorting cost. This expression makes the dependence on the number of slices explicit. If latexmath:[$K$] grows with latexmath:[$D$], the projection term changes accordingly. The paper discusses distributing slices across GPUs, which can increase the number of directions without requiring all projections to be handled by a single device.

The project page describes the method as linear in its scaling factors and highlights distributed slices. That statement should be read with the chosen scaling convention stated. It does not make the computation independent of batch size, embedding dimension or slice count.

[#unique_section_ch4_038_what_the_experiments_show]
=== What the experiments show

The authors report experiments on low-quality, long-tailed and low-rank data regimes, as well as out-of-distribution evaluation. They report strong OOD linear-probe performance at ImageNet-1K scale and comparable average OOD performance to DINOv2 in a comparison where VISReg is pretrained on ImageNet-22K and DINOv2 on the larger LVD-142M dataset. These comparisons depend on the exact model, data, metrics and benchmarks used in the paper.

The collapse-gradient comparison should be described as the authors’ controlled experiment. It is not a proof that all SIGReg implementations will fail or that VISReg cannot collapse under any possible training condition. The strongest conclusion is narrower: within the studied setups, the explicit scale term provides a different gradient path near collapse, and the decoupled design showed useful empirical behaviour across the evaluated data regimes.

[#unique_section_ch4_040_related_jepa_directions_modalities_and_uncer]
== Related JEPA directions: modalities and uncertainty

The image and video examples are the main progression of this chapter. Other JEPA papers extend the same predictive idea to additional modalities or change the mathematical treatment of uncertainty. They are important to recognize, but they do not all define one unified architecture.

[#unique_section_ch4_041_audio_prediction]
=== Audio prediction

A-JEPA (Fei, Fan and Huang, 2023) applies joint-embedding prediction to audio. Its inputs are represented through time-frequency structure, and its masking strategy accounts for the fact that time and frequency axes have different meanings. Audio-JEPA (Tuncay and colleagues, 2025) is a separate work with a separate method and evaluation. It uses masked audio representations and evaluates learned features on audio tasks. A-JEPA and Audio-JEPA should not be merged because the names are similar.

The general design choice is the same as in image and video JEPA: select a context, define a target representation, and predict the target in the embedding space. But the target geometry changes. A time-frequency patch is not interchangeable with an image patch, and the mask should reflect the structure of the signal.

[#unique_section_ch4_042_vision_language_prediction]
=== Vision-language prediction

VL-JEPA (Chen and colleagues, ICLR 2026) predicts continuous embeddings of target text rather than autoregressively generating token sequences during its main predictive training. The model is trained to align visual context with a representation of language. A text decoder is used when a textual answer must be produced. The paper evaluates retrieval, open-vocabulary recognition and visual question answering.

This is a useful demonstration that the target embedding need not be visual. It is not a guarantee that a visual-language embedding contains the physical state needed for manipulation. A language-aligned representation is optimized for cross-modal tasks; control sufficiency remains a separate requirement.

[#unique_section_ch4_043_variational_and_probabilistic_formulations]
=== Variational and probabilistic formulations

Two 2026 works use related but distinct names and should be differentiated carefully.

*Var-JEPA* (Gögl and Yau, ICML 2026) derives a variational formulation by making an underlying coupled latent-variable structure explicit. It introduces an evidence lower bound (ELBO) and studies uncertainty-aware latent prediction. The paper instantiates the approach for tabular data through Var-T-JEPA. Its central claim is that a deterministic JEPA can be understood as a special case of a more explicit variational construction under the paper’s model class.

*VJEPA* (Huang, ICML 2026) is a different paper. It proposes probabilistic prediction distributions over future latent states and connects the model to predictive state representations and Bayesian filtering. The paper also introduces Bayesian JEPA, which combines learned dynamics with modular prior experts through a Product of Experts. It evaluates uncertainty-aware predictions in several benchmark settings, including continuous-control tasks.

The names are easy to confuse. Var-JEPA and VJEPA are separate ICML papers with different authors, methods and empirical scope. Neither should be described as merely a new version of V-JEPA for video. In this chapter, the deterministic JEPA examples are sufficient to develop the main architecture; the variational papers provide a compact pointer toward probabilistic latent prediction.

[#unique_section_ch4_045_action_conditioned_prediction_and_planning]
== Action-conditioned prediction and planning

Passive video prediction is not yet a model of an agent’s interventions. If a robot observes a cup moving across a table, the frames alone may not reveal whether the motion came from the robot, another person, gravity or an external disturbance. To predict the consequence of a candidate action, the model must receive action information and be trained on data that connect actions to subsequent observations.

An action-conditioned world model predicts a future representation from a history of observations and controls. A schematic form is

[latexmath]
++++
\[
\hat z_{t+1:t+H}
=
g_\phi(z_{t-L:t},a_{t:t+H-1},s_{t-L:t}),
\]
++++
where latexmath:[$z$] denotes visual features, latexmath:[$a$] the action sequence, and (s) optional proprioceptive or end-effector state. The exact history length, action representation, conditioning mechanism and rollout target differ across implementations.

This extra input changes the identification problem. Passive pretraining can learn regularities in how the world usually evolves. Action-conditioned training must learn how the predicted future changes when the action changes. A model can be accurate on observed trajectories and still fail to answer counterfactual questions if the training data do not cover the relevant action-state combinations.

[#unique_section_ch4_046_from_prediction_to_planning]
=== From prediction to planning

Once a model can roll candidate actions forward in latent space, a planner can evaluate possible futures without decoding every pixel. Given a current latent state latexmath:[$z_t$], candidate action sequence latexmath:[$mathbf a_{t:t+H-1}$], and goal representation latexmath:[$z_g$], a basic objective is

[latexmath]
++++
\[
\mathbf a^*
=
\arg\min_{\mathbf a}
\mathcal C\left(
\hat z_{t+1:t+H}(\mathbf a),z_g
\right)
+
\lambda\mathcal R(\mathbf a).
\]
++++
The first term measures predicted compatibility with the goal; the second can penalize action magnitude, infeasible controls or other constraints. This is a conceptual decomposition, not a universal objective used by every JEPA system.

A planner usually optimizes a sequence but executes only the first action or a short prefix. It then receives a new observation, updates its state estimate, and replans. This is model-predictive control. Replanning limits the period during which the system relies on an open-loop prediction, but does not remove errors in the learned model or guarantee safety.

Several design choices interact:

* *Horizon:* a longer rollout gives the planner more foresight but allows prediction errors to compound.
* *Action representation:* low-level motor commands, end-effector deltas and temporally extended actions define different control problems.
* *Proprioception:* robot state may disambiguate visually similar scenes or indicate the current configuration of the arm.
* *Predictor architecture:* temporal context, action conditioning and normalization determine how the model uses its inputs.
* *Planner:* random shooting, the cross-entropy method, gradient optimization and other optimizers have different assumptions and failure modes.
* *Goal and cost:* latent distance is a proxy for task success. It may ignore collisions, force constraints, hidden state or irreversible outcomes.

A strong planning result is therefore a result about a complete system: encoder, predictive model, action data, planner, objective, environment and feedback loop.

[#unique_section_ch4_047_v_jepa_2_ac_as_a_staged_example]
=== V-JEPA 2-AC as a staged example

V-JEPA 2-AC makes the division between representation and dynamics explicit. The V-JEPA 2 visual encoder is first trained with action-free video and image data. The second stage freezes the visual encoder and trains an action-conditioned predictor using robot trajectories. The predictor uses past frame features, robot actions and end-effector states to estimate future frame features.

The post-training data are much smaller than the passive pretraining corpus. The V-JEPA 2 paper reports less than 62 hours of unlabeled robot video from DROID for the action-conditioned stage. The system is deployed on Franka arms in two laboratories and plans toward image goals. Its zero-shot claim is tied to the evaluated deployment environments and tasks; the model still uses robot interaction data during post-training.

This staged strategy separates two forms of knowledge. Large-scale passive video pretraining builds broad visual representations. Robot trajectories add information about the relation between control variables and future observations. The action-conditioned predictor is not obtained simply by relabelling an action-free predictor as a world model.

[#unique_section_ch4_048_the_broader_jepa_wm_design_space]
=== The broader JEPA-WM design space

The JEPA-WMs study by Terver and colleagues (2025/2026) investigates which model and planning choices contribute to physical planning performance. It examines visual encoders, predictor architecture and depth, the number of rollout steps used during training, context length, proprioception, model scaling, and planning optimizers. The paper evaluates simulated environments and real-robot data, and combines its ablations into a proposed model that outperforms the DINO-WM and V-JEPA 2-AC baselines on the reported navigation and manipulation evaluations.

This is valuable because it shifts attention from a single pretraining objective to the entire model-planner interface. Multi-step rollout training is intended to improve predictions beyond the immediate next step. Proprioception can help the predictor distinguish states that appear similar visually. The choice of planner determines how effectively the learned model can be searched. The results remain tied to the paper’s experimental tasks and baselines.

The official JEPA-WMs repository contains code, datasets and checkpoints. Its license is CC BY-NC-ND 4.0, so code and model artifacts should not be copied into a commercial textbook. The chapter can describe the architecture and reported experiments in its own words, with attribution, without reproducing restricted code.

[#unique_section_ch4_049_energy_based_prediction_and_planning]
=== Energy-based prediction and planning

Energy-based models provide a complementary way to score compatibility. An energy function (E(x,y)) assigns a scalar to a pair or configuration. Lower energy means the configuration is preferred under the model’s learned scoring convention. An energy function is not automatically a normalized probability distribution. To obtain a Gibbs density, one would need a partition function:

[latexmath]
++++
\[
p(y\mid x)
=
\frac{\exp[-E(x,y)]}{Z(x)},
\qquad
Z(x)=\int \exp[-E(x,y')]\,dy'.
\]
++++
For complex continuous spaces, computing (Zlatexmath:[$x$]) can be intractable. Many energy-based systems therefore use the energy as a score or objective without explicitly evaluating a normalized density.

In a predictive world model, energy can score whether a proposed future representation is compatible with the context or whether a trajectory satisfies a desired constraint. In an agent architecture, a cost can instead express a task objective or discomfort. These uses are related but not identical. A prediction loss measures mismatch to a training target; an energy scores compatibility; a task cost ranks futures according to goals. The same scalar notation should not hide these different semantics.

EB-JEPA is an official Meta FAIR library and tutorial for JEPA-style representation learning, prediction and planning. Its examples include image JEPA, video JEPA and action-conditioned video JEPA for planning in a Two Rooms environment. The repository is Apache-licensed. It is a useful executable reference, but it should be described as a library and collection of examples, not casually equated with a separate foundational theorem about energy-based learning.

[#unique_section_ch4_050_a_path_towards_autonomous_machine_intelligen]
== A path towards autonomous machine intelligence

In _A Path Towards Autonomous Machine Intelligence_ (2022), Yann LeCun proposes a cognitive architecture for agents that learn to predict, reason and plan from observation and interaction. The paper is explicit about its status: it is a position paper expressing a research vision, not a conventional scholarly article reporting one complete implemented system. Its value for this chapter is architectural. It places predictive world models inside a wider agent that has perception, memory, intrinsic objectives, an actor and a mechanism for configuring the system.

The proposal should therefore be taught as a design framework. Later systems such as V-JEPA 2-AC and JEPA-WMs instantiate parts of the broader idea, but they should not be presented as complete implementations of every module in the 2022 proposal.

[#unique_section_ch4_051_the_six_module_architecture]
=== The six-module architecture

The architecture has six top-level modules:

[arabic]
. *Perception* estimates the current state of the world from observations.
. *World Model* predicts possible future states under imagined action sequences.
. *Cost* evaluates current and predicted states through a scalar energy.
. *Actor* proposes action sequences and ultimately sends actions to effectors.
. *Short-Term Memory (STM)* stores relevant past, current and predicted states together with associated intrinsic costs.
. *Configurator* configures the other modules for the task at hand.

The Cost module contains two submodules, not two additional top-level modules. The *Intrinsic Cost* is described as immutable and computes immediate intrinsic energy from a state. The *Trainable Critic* estimates future intrinsic cost. Their outputs contribute to the Cost module’s scalar energy.

This hierarchy matters in the figure. Cost is one of the six peers in the architecture. Intrinsic Cost and Critic belong inside it.

[#unique_section_ch4_052_perception_estimate_the_current_state]
=== Perception: estimate the current state

The Perception module transforms observations into an internal state representation. It need not preserve every pixel or sensor value. It should retain what matters to the configured task and to future predictions. Its state estimate is the interface used by the Actor, World Model and Cost.

This links the architecture to the representation contract from Chapter 2. The state is task-dependent: a representation adequate for object recognition may omit velocity, contact state or another variable needed for manipulation. The Configurator can modulate Perception so that the representation serves the task being performed.

[#unique_section_ch4_053_world_model_imagine_possible_futures]
=== World Model: imagine possible futures

The World Model predicts future world states as a function of imagined action sequences proposed by the Actor. It is not merely a next-frame predictor. The proposed agent needs to represent multiple plausible futures because the world may be partially observed, stochastic, chaotic or influenced by other agents.

The paper emphasizes two open requirements: representing uncertainty and multiple possible predictions, and learning a predictive model that can support planning. A deterministic point predictor may be inadequate when several futures remain plausible. The architecture leaves room for hierarchical JEPA models that predict at multiple levels of abstraction and over different time horizons.

The World Model also interacts with STM. It can retrieve relevant past states, store new states, predict futures, and use memory when completing or correcting an estimate of the current world. This makes memory part of predictive computation rather than an isolated log of the past.

[#unique_section_ch4_054_cost_intrinsic_energy_and_a_trainable_critic]
=== Cost: intrinsic energy and a trainable critic

The Cost module emits a scalar called energy. In the proposal, the objective is to prefer states with lower long-run intrinsic cost. The module has two components:

* *Intrinsic Cost* is immutable and maps a current or predicted state to an immediate intrinsic energy. LeCun’s examples include pain, pleasure, hunger, satiety, curiosity and other basic drives.
* *Trainable Critic* predicts future values of intrinsic cost. It can use states retrieved from memory and is trained to estimate the longer-term consequences associated with a state.

The immediate cost and the critic’s prediction have different roles. The intrinsic term defines the basic drives or preferences. The critic estimates how those drives are likely to evolve. Their combination provides a scalar signal that can evaluate imagined trajectories.

The term _energy_ should not be misread as an automatically normalized probability. In this architecture it is a cost-like scalar used for ranking states and action sequences. A Gibbs probability would require an explicit normalization and a defined base measure. The paper’s use of energy is compatible with an optimization objective without claiming that every energy value is a calibrated probability.

A second distinction is between this agent-level Cost and the predictive loss used to train a JEPA encoder. The prediction loss encourages an embedding to match a target. Intrinsic energy evaluates a state according to the agent’s drives. A training loss, a compatibility energy and a task cost can all be scalar quantities, but they represent different functions.

[#unique_section_ch4_055_actor_propose_actions_and_optimize_trajector]
=== Actor: propose actions and optimize trajectories

The Actor proposes action sequences. The World Model predicts the outcomes associated with those sequences and sends the predicted states to Cost. Cost evaluates the expected energy of each candidate. The Actor can use the resulting gradient with respect to the proposed actions to optimize a sequence, at least when the relevant modules are differentiable. For discrete actions, the paper discusses alternatives such as dynamic programming.

The system sends the first action or a short prefix to the effectors, observes the result, updates its state estimate and repeats the process. This is closely related to model-predictive control. It limits commitment to an open-loop sequence while retaining the ability to plan over a longer horizon.

The architecture assumes differentiability along the paths used for gradient-based planning. The external physical environment is not a differentiable module through which gradients can generally be back-propagated. The system can differentiate through its learned Perception, World Model, Cost and Actor components, then execute an action and obtain a new observation from the real environment. The diagram must not suggest that gradients pass through the robot or physical world itself.

[#unique_section_ch4_056_short_term_memory_associative_access_to_rele]
=== Short-Term Memory: associative access to relevant states

STM stores relevant past, current and predicted states together with associated intrinsic costs. The World Model can query memory, retrieve values and store new states during temporal prediction or spatial completion. The Critic can retrieve past states and their observed intrinsic costs when learning to estimate future cost.

The paper describes an associative memory inspired by key-value memory networks. The point is not simply to append a longer observation history to a transformer. An associative memory can retrieve a past state that is relevant to the current query even when it is not adjacent in time. This is especially useful when an agent encounters recurring configurations or must recall a state whose consequences were previously experienced.

The label _Short-Term_ should not be taken to mean that memory only stores a fixed number of recent frames. The proposal describes memory over past, current and predicted states. Its exact capacity, retrieval rule and update policy remain open implementation choices.

[#unique_section_ch4_057_configurator_task_dependent_executive_contro]
=== Configurator: task-dependent executive control

The Configurator is an executive module. Given a task, it configures Perception, World Model, Cost and Actor. It can modulate the parameters of the modules it controls, choosing which state variables matter, which predictions should be made, what costs define success, and which policy or planner should be used.

This is not equivalent to adding a task embedding to a fixed network. The proposed role is broader: configuring the functional behaviour of several modules for the task at hand. The Configurator also receives information from the other modules in the architecture. It is therefore not simply a one-way instruction input.

[#unique_section_ch4_058_a_proposal_not_a_completed_blueprint]
=== A proposal, not a completed blueprint

The six-module architecture is valuable because it forces several responsibilities to be separated. A predictive representation is not a goal. A goal is not a controller. A controller is not memory. A memory is not a mechanism for deciding which problem should be solved. By making these modules explicit, the proposal exposes the research needed to connect representation learning with autonomous behaviour.

The framework does not specify a finished algorithm for every module or guarantee that joint differentiable optimization will be stable. It does not settle how intrinsic drives should be chosen, how the Critic should generalize, how memory should be retrieved, how multiple futures should be represented, or how a Configurator should learn to reconfigure a complex agent. Those are research questions rather than solved details.

[#unique_section_ch4_059_mode_1_mode_2_and_hierarchical_planning]
== Mode 1, Mode 2 and hierarchical planning

LeCun’s proposal distinguishes two ways an agent can select an action. Mode 1 produces an action reactively from the current state, possibly using short-term memory. Mode 2 uses the World Model and Cost to imagine candidate action sequences and search for a lower-cost future. These modes are not two different kinds of intelligence in a strict psychological taxonomy. They are two computational operating modes in the proposed architecture.

[#unique_section_ch4_060_mode_1_reactive_behaviour]
=== Mode 1: reactive behaviour

In Mode 1, Perception estimates the current state latexmath:[$s_t$], and a policy component of the Actor maps that state to an action:

[latexmath]
++++
\[
a_t=A(s_t).
\]
++++
The policy may also read STM, for example to retrieve an action associated with a similar past state. It need not run a multi-step planning procedure for every action. The Configurator adjusts the policy for the task.

Mode 1 is computationally inexpensive at inference time because it can use a single forward pass through a policy. It can be sophisticated and can incorporate memory. Its defining feature is that it does not deliberately search through imagined action sequences using the World Model and Cost on each decision.

The proposed architecture can still update the World Model while operating in Mode 1. It can predict the next state, execute the selected action, receive the next percept and use the observed state as a target for predictive learning. Thus, reactive action selection does not imply that the model ceases to learn from transitions.

[#unique_section_ch4_061_mode_2_reason_by_simulating_and_evaluating]
=== Mode 2: reason by simulating and evaluating

Mode 2 uses the predictive model as an internal simulator. A typical episode follows this sequence:

[arabic]
. Perception estimates the current state and Cost evaluates its immediate energy.
. Actor proposes an initial action sequence.
. World Model predicts one or more possible state sequences under those actions.
. Cost evaluates the predicted states, often by accumulating per-step energy.
. Actor changes the proposed actions to reduce the estimated total cost.
. After optimization or search, the system executes the first action or a short prefix.
. The next observation updates the state, and the process repeats.

A deterministic shorthand is

[latexmath]
++++
\[
s_{t+1}=F_\theta(s_t,a_t),
\qquad
J(\mathbf a)=\sum_{t=1}^{H}C(\hat s_t).
\]
++++
The Actor searches for an action sequence with low predicted cost. If the learned model and cost are differentiable, gradients can be propagated through the imagined rollout to the action variables. If actions are discrete or the objective is discontinuous, dynamic programming, combinatorial search, tree search or gradient-free optimization may be more appropriate.

The real environment is not part of this differentiable computation graph. The agent differentiates through its learned model and cost, then executes an action in the world and obtains a new observation. This distinction is central to why a world model is useful: it permits many candidate sequences to be evaluated internally without physically executing all of them.

Mode 2 resembles model-predictive control. A plan is optimized over a horizon, but only its first action or a short prefix is executed. New observations are used to re-estimate the state and replan. This feedback loop limits the duration of open-loop commitment, although it cannot prevent systematic model error or guarantee safe execution.

[#unique_section_ch4_062_distilling_deliberation_into_a_reactive_skil]
=== Distilling deliberation into a reactive skill

Repeatedly running Mode 2 can be expensive. The World Model is a shared reasoning resource, and deliberative search repeatedly rolls it forward for candidate action sequences. LeCun proposes using the outputs of Mode 2 to train a reactive policy.

Let latexmath:[$\tilde a_t$] be the action selected by Mode-2 optimization for state latexmath:[$s_t$]. A policy latexmath:[$A_\psi$] can be trained to imitate it:

[latexmath]
++++
\[
\mathcal L_{policy}
=
\mathbb E_{s_t}
D\left(\tilde a_t,A_\psi(s_t)\right),
\]
++++
where latexmath:[$D$] is an action-space divergence or regression loss appropriate to the action representation. Once trained, the policy approximates the expensive planning result with a direct state-to-action mapping. This is a form of amortized inference: compute a costly answer for sampled states, then learn a faster function that approximates those answers.

The reactive policy can be used directly in Mode 1, or to initialize an action sequence before Mode 2 refines it. The proposal therefore does not require choosing one mode permanently. Deliberative planning can create or improve a skill, while a reactive policy executes that skill efficiently.

This is related to policy distillation and imitation learning, but the teacher here is the agent’s own planner. The target action is produced by minimizing the model’s estimated cost, not necessarily by copying an external expert. It inherits the planner’s model bias and cost design: a policy can only imitate the plan that the learned system considers good.

[#unique_section_ch4_063_hierarchical_jepa_and_multiple_time_scales]
=== Hierarchical JEPA and multiple time scales

The proposal extends JEPA from a single predictive mapping to a hierarchy of representations and predictive models. A lower level can represent detailed perceptual states and short motor actions. Higher levels can represent temporally extended events, abstract state changes or action segments. A high-level model can predict a more distant target in a coarser representation, while a lower-level model predicts the intermediate states needed to realize that target.

One way to express the idea is to let latexmath:[$s_t^{(0)}$] denote a fine-scale state and latexmath:[$s_t^{(1)},s_t^{(2)},\ldots$] denote increasingly abstract states. Each level predicts a target at its own time scale:

[latexmath]
++++
\[
\hat s_{t+\Delta_k}^{(k)}
=
F_k(s_{\leq t}^{(k)},a_{t:t+\Delta_k}).
\]
++++
This is schematic notation for a hierarchy, not a canonical implementation specification. The important structure is that a high-level plan can constrain the subgoals or action sequences of lower levels, while the lower levels provide the detailed predictions required to carry out the plan.

Hierarchical prediction is motivated by long-horizon planning. A planner that reasons directly over every low-level control step may face an enormous search space. Temporally extended representations and action chunks can shorten the effective horizon at the high level. Yet abstraction creates its own risk: if a high-level state discards a variable needed by a low-level controller, the plan may be impossible to execute.

[#unique_section_ch4_064_multiple_futures_and_uncertainty]
=== Multiple futures and uncertainty

A deterministic model returns one predicted trajectory for a given starting state and action sequence. But the future can be uncertain for several reasons:

* *Aleatoric uncertainty:* the environment itself is stochastic.
* *Partial observability:* the state representation does not contain all relevant information.
* *Epistemic uncertainty:* the learned model is imperfect because of limited data, model capacity or optimization.
* *Other agents:* other people or systems may make decisions that change the outcome.

The proposal argues that a World Model should represent multiple plausible futures rather than collapse them into a single prediction. This is particularly important when the action sequence does not uniquely determine the outcome. A model that averages mutually exclusive futures can produce a latent state that corresponds to neither outcome.

There are several possible ways to address this problem, including latent-variable models, ensembles, stochastic predictors or explicit distributions over future embeddings. These approaches have different assumptions and computational trade-offs. The 2022 proposal does not prescribe one definitive solution. The later VJEPA and Var-JEPA papers provide probabilistic directions, but they do not solve every uncertainty problem in physical planning.

== Reading a miniature JEPA system

This section turns the chapter’s architecture into an implementation workflow. It does not introduce a new experiment or claim a reproduction. The aim is to give the reader a stable mental model for reading official implementations and for identifying which parts of a JEPA are method-defining rather than incidental engineering.

The official I-JEPA repository is a useful reference for image masking, target encoders, predictor queries and distributed training. Its source tree separates the training loop, model definitions, mask collators, data transforms and experiment configurations. The official V-JEPA 2 repository contains separate training and evaluation paths for action-free pretraining, V-JEPA 2-AC post-training and V-JEPA 2.1. The separation in the repository mirrors a substantive difference in the methods.

[#unique_section_ch4_066_a_generic_teacher_student_jepa_training_step]
=== A generic teacher-student JEPA training step

For an EMA-target JEPA such as the image and video examples discussed earlier, one training step can be summarized as follows:

[arabic]
. Sample an observation or clip.
. Sample a context and one or more target regions.
. Encode visible context tokens using the trainable context encoder.
. Encode target tokens using the slowly updated target encoder.
. Build a query containing the target’s position or time information.
. Predict target embeddings from context embeddings and the query.
. Compute a feature-space prediction loss.
. Add any method-specific regularization and update the trainable parameters.
. Update the target encoder with the method’s EMA rule.

The following pseudocode is deliberately generic. It is not copied from the I-JEPA or V-JEPA repositories and should not be mistaken for a runnable implementation.

[source,text]
----
context, target, query = sample_context_and_target(batch)

z_context = context_encoder(context)
with no_gradient():
    z_target = target_encoder(target)

z_prediction = predictor(z_context, query)
loss = feature_distance(z_prediction, z_target)
loss = loss + regularizer_if_used(z_context, z_target)

update(context_encoder, predictor, loss)
target_encoder = ema_update(target_encoder, context_encoder)
----

The pseudocode assumes a target branch that is updated by EMA. It does not describe every JEPA. LeJEPA uses multi-view prediction and SIGReg without the same EMA teacher-predictor arrangement. VISReg changes the regularization term. V-JEPA 2-AC uses an action-conditioned temporal predictor and a separate post-training stage. A diagram or algorithm that silently combines these recipes would describe a method that none of the cited papers actually proposes.

[#unique_section_ch4_067_the_data_pipeline_carries_the_inductive_bias]
=== The data pipeline carries the inductive bias

A training loop can look generic while the mask sampler determines most of the task. For I-JEPA, the relation between spatially distributed context and larger target blocks is central. For V-JEPA, targets and visible context are spatiotemporal. For V-JEPA 2-AC, the action and robot-state sequence must be aligned with the visual feature history and the future targets. The sampler defines what the predictor is expected to infer.

The reader should therefore inspect the data pipeline before treating the loss as the whole algorithm. Check the clip sampling rate, temporal stride, image resolution, crop policy, target length, number of masks, overlap between context and target, and action/observation synchronization. These choices alter the prediction problem.

[#unique_section_ch4_068_what_must_be_inspected_in_an_official_implem]
=== What must be inspected in an official implementation

When reading a repository, follow one training batch all the way through:

* *Input:* how videos or images are decoded, sampled and normalized.
* *Masking:* how context and target regions are generated and encoded.
* *Encoder:* whether weights are shared, copied or EMA-updated.
* *Predictor:* which position, time or action variables condition it.
* *Target path:* where gradients are stopped and where they are allowed.
* *Loss:* whether it is pointwise feature regression, a multi-view objective, SIGReg, VISReg or another criterion.
* *Optimizer:* which parameters are updated by the gradient step.
* *Target update:* whether an EMA update is present and its schedule.
* *Evaluation:* whether features are frozen, linearly probed, fine-tuned or used in a planning system.

These checks prevent several common reading errors. An EMA target is not the same as a frozen pretrained backbone. A target mask is not necessarily a future-time mask. A predictor is not necessarily a pixel decoder. A training loss is not a planning cost. And a reported frozen-backbone result is not a test of closed-loop control.

== Summary and exercises

[#unique_section_ch4_073_summary]
=== Summary

A Joint-Embedding Predictive Architecture learns by predicting target representations from context representations. Unlike pixel reconstruction, this objective evaluates a prediction in feature space. The method’s meaning depends on how context, target, query, encoder, predictor and regularizer are defined.

I-JEPA applies the idea to masked image regions. Its target blocks and spatially distributed context determine what can be inferred. V-JEPA extends masked feature prediction to video and learns representations useful for appearance- and motion-centric tasks. Neither action-free I-JEPA nor V-JEPA should automatically be described as a model of interventions.

V-JEPA 2 separates action-free pretraining from action-conditioned post-training. V-JEPA 2-AC receives robot actions and end-effector state and predicts future visual features, enabling a planner to search toward image goals under the reported setup. V-JEPA 2.1 is a separate dense-feature learning recipe with visible-token and masked-token loss, deep supervision, multimodal tokenizers and scaling.

Distributional regularization addresses more than trivial collapse. VICReg controls variance and pairwise covariance. LeJEPA motivates an isotropic Gaussian target through a specific downstream prediction-risk analysis and uses SIGReg to compare projected empirical characteristic functions with a standard-normal target. The finite, resampled projections are a practical sketch, not a population-level certificate. VISReg decouples scale and shape: a variance term controls the coordinate-wise spread, a sliced-Wasserstein term compares sorted projections with Gaussian quantiles, and a centering term controls the batch mean. Its scalar scale gradient should not be mistaken for a universal lower bound on every network parameter gradient.

Other JEPA directions extend the target to audio, language or probabilistic latent states. A-JEPA and Audio-JEPA are separate works. VL-JEPA predicts text embeddings from visual context. Var-JEPA and VJEPA are separate variational papers, not versions of V-JEPA.

Action-conditioned prediction links a latent world model to planning. A planner searches over actions using predicted future representations and a goal or cost. Energy, prediction loss and task cost are different quantities. A scalar energy is not automatically a normalized probability.

LeCun’s six-module architecture places Perception, World Model, Cost, Actor, Short-Term Memory and Configurator inside one proposed agent design. Intrinsic Cost and the Trainable Critic are submodules within Cost. Mode 1 uses a reactive policy. Mode 2 performs deliberative planning through the World Model and Cost. Mode-2 plans can train a faster Mode-1 policy by imitation. Hierarchical JEPA and uncertainty-aware futures are proposed routes to long-horizon planning, not solved guarantees.

The chapter’s main conclusion is that predictive representations are a component of a world model, and a world model is a component of an autonomous agent. Reliable action requires additional machinery: action-linked data, predictive dynamics, goals or costs, planning, feedback, memory and task configuration.

. *Spatial versus temporal prediction.* Give an example in which predicting a hidden image region is useful but does not require predicting the future. Give a second example in which a future frame cannot be predicted adequately without temporal context. Explain how the target sampler changes the task.

Give a scene configuration for which the distributed context may provide more useful evidence for a distant target block. State a situation in which the contiguous crop might instead be preferable.

Explain why the characteristic function is differentiable with respect to the samples. Why does a finite set of projected directions not prove exact equality of two multivariate distributions?

Explain why VISReg detaches the standard deviation in the shape normalization and why this does not by itself prove a universal lower bound on encoder-parameter gradients.
