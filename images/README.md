The second augmented view of an anchor is the positive; views from other source examples are sampled negatives. Because labels follow source identity rather than semantic equivalence, related examples can become false negatives. |
| 3.4 | `images/CH03_F05_Dadwal.md` | `images/CH03_F04_Dadwal.png` | InfoNCE: Candidate probabilities and gradients. Temperature-scaled similarities become softmax probabilities and cross-entropy loss. Gradient descent raises the positive logit and lowers negative logits, with a harder negative receiving the larger update. Values are illustrative. |
| 3.5 | `images/CH03_F07_Dadwal.md` | `images/CH03_F05_Dadwal.png` | Alignment and uniformity are distinct geometric requirements. Alignment measures how closely matched views lie; uniformity measures whether independent embeddings crowd together on the normalized sphere. These diagnostics describe geometry, not the amount of task-relevant information retained. |
| 3.6 | `images/CH03_F10_Dadwal.md` | `images/CH03_F06_Dadwal.png` | Momentum contrast: Query encoder, key encoder and queue. The query encoder receives contrastive gradients; a momentum-updated key encoder supplies the positive key and queue entries. The FIFO queue expands the candidate set, but stored features may become stale as the encoder changes. |
| 3.7 | `images/CH03_F12_Dadwal.md` | `images/CH03_F07_Dadwal.png` | CPC: Causal context predicts future latent candidates. Past observations form a causal context that scores future latents at several horizons against sampled candidates. Future targets are used for comparison, not context input; retrieval success alone does not demonstrate recursive rollout or planning. |
| 3.8 | `images/CH03_F13_Dadwal.md` | `images/CH03_F08_Dadwal.png` | Why agreement alone permits collapse. Mapping every input to one constant vector gives perfect agreement while erasing differences. A nonconstant encoder can also achieve zero agreement loss, so agreement alone cannot exclude collapse; target updates and other constraints matter. |
| 3.9 | `images/CH03_F14_Dadwal.md` | `images/CH03_F09_Dadwal.png` | BYOL and SimSiam: Similar predictors, different target updates. Both predict a detached representation from another view. BYOL updates a separate target encoder by exponential moving average; SimSiam shares its encoder across views and uses stop-gradient without an EMA target network. |
| 3.10 | `images/CH03_F15_Dadwal.md` | `images/CH03_F10_Dadwal.png` | DINO teacher-student cross-view distillation. A student matches the teacher's prototype distribution for another view of the same source. Centering and sharpening shape the teacher target; the student receives gradients while the teacher tracks it through an exponential moving average. |
| 3.11 | `images/CH03_F16_Dadwal.md` | `images/CH03_F11_Dadwal.png` | Barlow Twins: The cross-correlation matrix. The method standardizes paired-view features and drives their cross-correlation matrix toward identity: corresponding dimensions agree, while off-diagonal correlations shrink. This reduces linear redundancy but does not guarantee independence or semantic usefulness. |
| 3.12 | `images/CH03_F17_Dadwal.md` | `images/CH03_F12_Dadwal.png` | VICReg separates agreement, variance and covariance. The invariance term matches paired views, the variance term prevents constant dimensions, and covariance regularization discourages redundant directions. These constraints address distinct geometric failures but do not establish that retained variation is useful for the target. |
| 3.13 | `images/CH03_F23_Dadwal.md` | `images/CH03_F13_Dadwal.png` | One visible context, several masked-prediction targets. The mask determines which positions are hidden; the target defines what must be predicted: pixel values, discrete tokenizer codes, or teacher-derived features or distributions. These are alternatives, not one architecture using every target. |
| 3.14 | `images/CH03_F24_Dadwal.md` | `images/CH03_F14_Dadwal.png` | MAE's visible-only encoder and masked-patch decoder. Only visible patch tokens enter the encoder. The decoder restores the full sequence with mask tokens and predicts pixels for masked patches, reducing encoder computation at high mask ratios. Downstream tasks typically use the encoder features. |
| 3.15 | `images/CH03_F27_Dadwal.md` | `images/CH03_F15_Dadwal.png` | The training representation and the downstream interface. Pretraining may optimize the projector output, while downstream tasks often use backbone features. Those features can be exported as a pooled vector, spatial grid or temporal context; the interface determines which distinctions remain accessible. |
| 3.16 | `images/CH03_F28_Dadwal.md` | `images/CH03_F16_Dadwal.png` | Aliasing is a failure of predictive sufficiency. Two histories map to the same representation but imply different next-state distributions under the same action. A predictor given only that representation and action must return the same distribution for both, so it cannot predict both correctly. |
| 3.17 | `images/CH03_F22_Dadwal.md` | `images/CH03_F17_Dadwal.png` | A training loss and a probe answer different questions. No single metric certifies predictive sufficiency. Pretraining loss measures fit to its chosen target; a probe tests accessibility under a specified readout, while sufficiency requires evaluating a named target and prediction horizon on held-out data. |

## Production rules

- Original teaching schematics only; no pasted paper figures or implementation screenshots.
- White background, grayscale-safe dark line work and `#3B6FB6` as the only restrained accent. Flat 2D only; no gradients, 3D effects, Mermaid or decorative watermarks.
- Worked values are illustrative, not experiment results.
- Do not render figure numbers, titles, captions or prose descriptions inside artwork; the book layout supplies the number and caption separately.
- Use print-sized lettering, about 1–2 pt larger than a typical screen-first infographic, and check every label at book-column width.
- The deleted family map is not to be replaced with a new taxonomy. The method table is a navigation aid, not a claim of mutually exclusive families.
