# Chapter 3 code map

- **Book-facing examples:** [`minimal/`](minimal/README.md). Start here; each training script focuses on one learning mechanism.
- **Reference experiments:** `01_collect_dmc_data.py` through `12_assemble_encoder.py`, plus `table_03_04_comparison.py`. These include full experiment bookkeeping and reproduce the committed figures and metrics.

The short implementations are intentionally not bit-for-bit reproductions of the reference runs. Keep published numerical claims tied to the reference artifacts.
