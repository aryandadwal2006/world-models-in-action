# 3.4 The collapse problem and how it is avoided

### 3.4.1 Demonstrating collapse

Consider the simplest possible objective for two views of each frame: make their representations equal. Let $p_n^{(1)}$ and $p_n^{(2)}$ denote the vectors compared by the loss for the two views of frame $n$. For a batch of $N$ frames and representations of dimension $d$, define

$$
\frac{1}{Nd}
\sum_{n=1}^{N}
\left\lVert p_n^{(1)}-p_n^{(2)}\right\rVert_2^2.
$$

This objective is nonnegative. It reaches zero whenever the two views produce identical representations.

But it does not require different frames to produce different representations. Suppose the encoder returns the same constant vector for every input. Then every positive pair matches exactly, the loss is zero, and the objective has reached its global minimum. The solution works regardless of what the images contain. It does not need to represent cart position, pole angle, or any other aspect of the physical state.

This is complete collapse. All inputs map to one point.

There is also dimensional collapse. Here, the representation still varies across inputs, but its variation is restricted to only a few of the available dimensions. The encoder may produce a 32-dimensional vector while using only a small number of independent directions to distinguish observations.

These are different failure modes. We therefore need more than one measurement to diagnose them.

#### Measuring collapse

The first measurement is spread: the standard deviation of each coordinate across a collection of representations, averaged over all $d$ coordinates. If the encoder returns a constant vector for every input, the spread is zero. If its outputs become almost identical, the spread approaches zero.

Spread alone is not enough, however. A representation can use many independent directions while all its coordinates have very small values. Conversely, a representation can have large coordinate variation but vary mainly along one direction.

The second measurement is effective rank, which summarizes how many directions carry substantial variation.

Let $\lambda_1,\ldots,\lambda_d$ be the eigenvalues of the representation covariance matrix, and define the normalized eigenvalues

$$
q_j=\frac{\lambda_j}{\sum_{\ell=1}^{d}\lambda_\ell}.
$$

The effective rank is the exponential of the entropy of this distribution:

$$
\exp\left(-\sum_{j=1}^{d}q_j\ln q_j\right).
$$

If the variance is distributed equally across all $d$ directions, the effective rank is $d$. If all variation lies in one direction, the effective rank is one. Intermediate values indicate that variation is distributed across a smaller number of directions.

The normalization removes overall scale. Multiplying every representation by $10^{-5}$ does not change the effective rank, because all covariance eigenvalues are multiplied by the same squared factor and the normalized $q_j$ remain unchanged. This is useful for measuring dimensional collapse, but it means effective rank cannot detect a representation whose spread has shrunk almost to zero.

**Listing 3.7 — Measuring spread and effective rank**

The following excerpt is from the diagnostic code in ch03/06_collapse_demo.py. It computes both measurements from a matrix of representations.

```python
def feature_diagnostics(features):
    features = np.asarray(features, dtype=np.float64)
    centered = features - features.mean(axis=0, keepdims=True)
    singular_values = np.linalg.svd(centered, compute_uv=False)
    eigenvalues = singular_values ** 2                   #A
    total = float(eigenvalues.sum())
    if total <= 1e-15:
        rank = 0.0
    else:
        q = eigenvalues / total                           #B
        entropy = -np.sum(q * np.log(np.maximum(q, 1e-15)))
        rank = float(np.exp(entropy))                     #C
    spread = float(np.std(features, axis=0).mean())       #D
    return {"mean_dim_std": spread, "effective_rank": rank}
```

A The squared singular values give the covariance eigenvalues up to a common factor.

B Normalizes the eigenvalues, removing the influence of overall scale.

C Computes the effective rank from the entropy.

D Averages the standard deviation across representation coordinates.

The full repository function also validates its input and handles the degenerate all-zero case. We use this diagnostic on the encoder output, not just the projection head, because the encoder output is the representation retained for later use.

> **NOTE — Interpreting small spread**

A small spread is not, on its own, proof that a representation contains no information. A representation can encode distinctions at a small scale. The recorded experiment does not probe the attraction-only encoder for physical-state information, so we do not claim that its tiny variation is necessarily useless. The result is narrower: the objective does not demand spread or prevent a constant representation from minimizing the loss.

#### Why does NT-Xent behave differently? If all views map to the same nonzero vector, every cosine similarity is one. The positive and the negatives then have identical scores, so the probability assigned to the positive is $1/(2N-1)$ and the loss is $\ln(2N-1)$. The encoder cannot reduce the loss by distinguishing the positive from the negatives, because it has collapsed them all together. NT-Xent rewards a lower loss when the positive receives a higher score than the negatives.

The negative pairs therefore give contrastive learning a mechanism that attraction alone lacks. But they bring their own design choices, including the number and quality of the negatives. The next section examines alternatives that do not require them.

### 3.4.2 Three mechanisms in brief

SimSiam, BYOL, and Barlow Twins use different mechanisms to avoid collapse without contrastive negative pairs. Their shared starting point is that two views of the same frame should produce related representations. What differs is how each method prevents that requirement from being satisfied by an uninformative constant output.

The repository implements reduced-scale versions of all three methods. The study uses cart-pole frames, five random seeds, 30 epochs, up to 6,000 training frames, batch size 128, and Adam with learning rate $10^{-3}$. The encoder output has 32 dimensions, while the projection and predictor heads use 128-dimensional embeddings. These experiments examine the core mechanisms at small scale; they are not exact reproductions of the large-scale ImageNet experiments in the original papers.

#### SimSiam: stop the gradient through the target

SimSiam uses a shared encoder and projector for the two views, plus a predictor applied to one branch. Let $z_1,z_2$ be the projected representations and $p_1,p_2$ their predictor outputs.

For a predictor output $p$ and target representation $z$, define the negative cosine similarity:

$$
D(p,z)=-
\frac{p}{\lVert p\rVert_2}
\cdot
\frac{z}{\lVert z\rVert_2}.
\tag{3.9}
$$

The symmetric objective evaluates each view as the prediction and the other view as the target:

$$
\frac12D\big(p_1,\operatorname{sg}(z_2)\big)
+
\frac12D\big(p_2,\operatorname{sg}(z_1)\big)
\tag{3.10}
$$

The operator $\operatorname{sg}$ means stop-gradient. It leaves the target's value unchanged, but treats it as a constant when calculating the gradient. The predictor is trained to match the opposite branch's representation, while the target branch does not receive gradients through that particular loss term.

This asymmetry is central to SimSiam. The method also uses a projector and a predictor with batch normalization, following its original design. The stop-gradient changes the optimization process, but it is not a universal mathematical guarantee that every possible configuration avoids collapse. Its effectiveness is established primarily through the method's experiments, and our reduced-scale study measures the result of the full configuration rather than performing an ablation of each component.

#### BYOL: a slowly moving target

BYOL also compares online predictions with target representations, but its target branch is a separate network. The online network contains an encoder, projector, and predictor and is updated by gradient descent. The target network contains an encoder and projector, receives no gradient, and changes through an exponential moving average of the online parameters.

Let $\theta_o$ denote the online parameters, $\theta_t$ the target parameters, and $m\in[0,1$) the momentum. The update is

$$
\boxed{
\theta_t\leftarrow m\theta_t+(1-m)\theta_o
}
\tag{3.11}
$$

The target therefore changes gradually rather than tracking every online update immediately. The online network learns to predict the slowly changing target. In the repository implementation, the momentum starts at 0.99 and increases toward one during training using a cosine schedule.

The target network is not optimized by gradient descent. Its parameters are updated by the exponential moving average, which provides the asymmetry in BYOL's learning procedure. As with SimSiam, this mechanism is not a general proof of collapse prevention for every configuration. The experiment tests the implemented method at the declared scale and budget.

**Listing 3.8 — Stop-gradient and the target-network update**

Source: worldmodels/losses/noncontrastive.py.

```python
def simsiam_loss(p1, z2, p2, z1):
    def d(p, z):
        p = F.normalize(p, dim=1)
        z = F.normalize(z.detach(), dim=1)               #A
        return -(p * z).sum(dim=1).mean()                 #B

    return 0.5 * d(p1, z2) + 0.5 * d(p2, z1)             #C


def update_target_ema(online_model, target_model, decay=0.99):
    with torch.no_grad():
        for po, pt in zip(
            online_model.parameters(), target_model.parameters()
        ):
            pt.data.mul_(decay)                           #D
            pt.data.add_(po.data, alpha=1.0 - decay)
```

A Detaches the target from the gradient computation.

B Computes negative cosine similarity for the batch.

C Averages the two directions, as in equation 3.10.

D Moves the target parameters toward the online parameters, as in equation 3.11.

The code above contains two distinct mechanisms. SimSiam stops the gradient through the target representation; BYOL updates the target network by exponential moving average. They should not be conflated: BYOL's target-network update is not simply another spelling of SimSiam's stop-gradient.

#### Barlow Twins: reduce redundancy between coordinates

Barlow Twins takes a different approach. It standardizes each coordinate of the two embedding batches and computes their cross-correlation matrix. If the views agree coordinate by coordinate, the diagonal should approach one. If different coordinates are uncorrelated, the off-diagonal entries should approach zero.

Let $\hat z^A_{b,i}$ and $\hat z^B_{b,j}$ denote standardized coordinates $i$ and $j$ for frame $b$ in two view batches. The cross-correlation matrix is

$$
C_{ij}=\frac1N\sum_{b=1}^{N}
\hat z^A_{b,i}\hat z^B_{b,j}.
\tag{3.12}
$$

The loss penalizes deviation of diagonal entries from one and penalizes nonzero off-diagonal entries:

$$
\sum_i(1-C_{ii})^2
+
\lambda\sum_i\sum_{j\ne i}C_{ij}^2
\tag{3.13}
$$

The diagonal term rewards agreement across views. The off-diagonal term discourages different dimensions from carrying redundant, linearly correlated information. The implementation uses $\lambda=0.005$.

A constant coordinate cannot be standardized into a meaningful unit-variance signal. The code clamps the standard deviation at $10^{-6}$; if a coordinate is constant, its standardized values are zero, and its diagonal term contributes a penalty of one. Collapse therefore incurs a positive loss. However, because the method standardizes the features, this objective does not set a minimum scale for the unstandardized representation itself.

**Listing 3.9 — The Barlow Twins cross-correlation loss**

Source: worldmodels/losses/noncontrastive.py.

```python
def barlow_twins_loss(z1, z2, lambd=0.005):
    n, d = z1.shape
    s1 = z1.std(dim=0, unbiased=False).clamp_min(1e-6)
    s2 = z2.std(dim=0, unbiased=False).clamp_min(1e-6)
    a = (z1 - z1.mean(dim=0)) / s1                      #A
    b = (z2 - z2.mean(dim=0)) / s2
    c = a.T @ b / n                                     #B
    diag = (torch.diagonal(c) - 1).pow(2).sum()         #C
    off = ~torch.eye(d, dtype=torch.bool, device=z1.device)
    off_diag = c[off].pow(2).sum()                      #D
    return diag + lambd * off_diag
```

A Standardizes every coordinate across the batch.

B Computes the cross-correlation matrix in equation 3.12.

C Penalizes diagonal entries that differ from one.

D Penalizes off-diagonal correlations.

The mechanisms examined so far prevent collapse through asymmetry or relationships between coordinates. VICReg makes the requirements explicit in three terms: maintain agreement between views, keep variation in each coordinate above a floor, and reduce covariance between different coordinates.

### 3.4.3 VICReg: making the anti-collapse force explicit

VICReg stands for variance-invariance-covariance regularization. It receives two batches of embeddings, $Z^A$ and $Z^B$, each with $N$ rows and $d$ coordinates. It combines three terms, each with a distinct purpose.

#### The variance term

The variance term sets a floor on the standard deviation of each coordinate across a batch. Let $Z_{:,j}$ denote column $j$, and let $S$ be its regularized standard deviation:

$$
S(u)=\sqrt{\operatorname{Var}(u)+\epsilon}.
$$

The variance hinge is

$$
\boxed{
v(Z)=\frac1d\sum_{j=1}^{d}
\max\big(0,\gamma-S(Z_{:,j})\big)
}
\tag{3.14}
$$

Here, $\gamma$ is the minimum target standard deviation and $\epsilon>0$ stabilizes the square root. The repository uses $\gamma=1$ and $\epsilon=10^{-4}$.

The hinge is zero for a coordinate whose standard deviation is already at least $\gamma$. A coordinate below the threshold incurs a penalty proportional to the shortfall. The term therefore sets a floor; it does not reward arbitrarily increasing a coordinate's scale.

The small $\epsilon$ matters near zero variance. Without it, differentiating the square root at zero can produce an undefined or unbounded derivative. With $\epsilon=10^{-4}$, the derivative of $\sqrt{v+\epsilon}$ with respect to variance is bounded above by $1/(2\sqrt{\epsilon})=50$.

#### The invariance term

The invariance term asks the two views to produce similar embeddings. In the implementation, it is the mean squared error between matching rows:

$$
\boxed{
s(Z^A,Z^B)=
\frac{1}{Nd}
\sum_{n=1}^{N}
\left\lVert z_n^A-z_n^B\right\rVert_2^2
}
\tag{3.15}
$$

This is the positive-view attraction from the collapse demonstration, but now it is only one part of the objective. By itself, it would allow a constant representation. In VICReg, the variance and covariance terms constrain what solutions can minimize the total loss.

#### The covariance term

The covariance term discourages redundancy between different coordinates. Let $\bar z$ be the mean row of the batch. Define the sample covariance matrix

$$
C(Z)=\frac{1}{N-1}
\sum_{n=1}^{N}
(z_n-\bar z)(z_n-\bar z)^\top.
$$

Its diagonal contains the coordinate variances. Its off-diagonal entries contain the covariances between different coordinates. The VICReg covariance term penalizes squared off-diagonal entries:

$$
\boxed{
c(Z)=\frac1d
\sum_{i\ne j}[C(Z)]_{ij}^{2}
}
\tag{3.16}
$$

If all off-diagonal entries are zero, the coordinates are pairwise uncorrelated in the batch. This reduces second-order redundancy, but it does not establish that the coordinates are statistically independent: nonlinear dependence can remain even when covariance is zero.

#### Combining the three terms

#### The total VICReg loss is a weighted sum

$$
\boxed{
\begin{aligned}
L_{\mathrm{VICReg}}
={}&\lambda s(Z^A,Z^B)\\
&+\mu\big[v(Z^A)+v(Z^B)\big]\\
&+\nu\big[c(Z^A)+c(Z^B)\big].
\end{aligned}
}
\tag{3.17}
$$

The implementation uses $\lambda=25$, $\mu=25$, and $\nu=1$. These coefficients set the relative influence of invariance, variance, and covariance penalties. Both embedding batches receive their own variance and covariance penalties.

Consider what the three terms do to degenerate solutions.

**A constant representation.** If every coordinate is constant across the batch, the invariance term is zero and the covariance term is zero. But the regularized standard deviation of each coordinate is only $\sqrt{\epsilon}=0.01$. With $\gamma=1$, each coordinate incurs a variance-hinge penalty of $0.99$. Across both views, the weighted variance term adds $25\times2\times0.99=49.5$ to the total loss. Collapse is no longer a zero-cost solution.

**A single repeated direction.** Suppose all coordinates are identical copies of one unit-variance scalar. The views can match and every coordinate meets the variance floor, so the invariance and variance terms can both be zero. But every off-diagonal covariance equals one. With $d=16$, there are $16\times15=240$ off-diagonal entries, and the covariance cost for each batch is $240/16=15$. Across the two views, the covariance term contributes 30. This discourages dimensional collapse into one repeated direction.

**Unrelated but varied embeddings.** A model could produce embeddings with sufficient variance and little coordinate covariance without making the two views of the same frame agree. The variance and covariance terms would not necessarily penalize this configuration, but the invariance term would. It is the term that ties the representations of paired views together.

These examples show why no one of the three terms replaces the others. Variance prevents coordinates from becoming constant, covariance discourages redundancy, and invariance links representations of positive views. Their combination makes the constraints explicit, instead of relying solely on the behavior of the training procedure.

**Supplementary code excerpt — VICReg loss (not a numbered listing)**

Source: worldmodels/losses/vicreg.py.

```python
def vicreg_loss(za, zb, sim_coeff=25.0, std_coeff=25.0,
                cov_coeff=1.0, gamma=1.0, eps=1e-4):
    n, d = za.shape
    sim = F.mse_loss(za, zb)                             #A

    def variance(z):
        v = z.var(dim=0, unbiased=False)
        std = torch.sqrt(v + eps)                        #B
        return F.relu(gamma - std).mean()                #C

    def covariance(z):
        z = z - z.mean(dim=0)
        cov = (z.T @ z) / (n - 1)                       #D
        off = ~torch.eye(d, dtype=torch.bool, device=z.device)
        return cov[off].pow(2).sum() / d                 #E

    var = variance(za) + variance(zb)
    cov = covariance(za) + covariance(zb)
    total = sim_coeff * sim + std_coeff * var + cov_coeff * cov
    return total, sim, var, cov
```

A Computes the invariance term from equation 3.15.

B Computes the regularized standard deviation used by equation 3.14.

C Penalizes coordinates whose standard deviation is below $\gamma$.

D Computes the batch covariance matrix.

E Sums the squared off-diagonal entries, divided by $d$.

The variance calculation uses population variance, while the covariance estimate divides by (N-1), matching the repository implementation. The function returns the total loss and each of its three components so the training script can record their behavior separately.

VICReg avoids explicit negative pairs, but that does not make it free of design choices. The covariance matrix is estimated from a finite batch, and the coefficients $\lambda,\mu,\nu$ determine the balance between the three terms. The methods in this section address collapse through different mechanisms: NT-Xent uses negative pairs, SimSiam and BYOL introduce asymmetric training paths, Barlow Twins reduces cross-correlation, and VICReg imposes explicit variance and covariance constraints. None of these mechanisms alone establishes that the resulting representation is a sufficient physical state. 3.5 Masked prediction

Contrastive learning pays the encoder to make two views of the same observation agree. Masked prediction uses a different signal: hide part of an observation, then train a model to reconstruct what is missing. Neither method receives the simulator's physics state as a target, but the two objectives ask the encoder to preserve different information.
