# First principles: representation objectives, invariance and evaluation

## 1. The representation problem

Let X be an observation drawn from a data distribution and let an encoder f with parameters θ map the observation to a feature vector z=fθ(x). The purpose is not compression for its own sake. The representation should discard nuisance variation while retaining distinctions relevant to the intended downstream task. “Relevant” is not intrinsic to the pixels: it depends on what a future predictor, decision rule or agent must do.

Suppose a latent situation s produces observations through a rendering or sensor process. An ideal state encoder would preserve information about the aspect of s that determines future observations and rewards under actions. A self-supervised objective rarely observes that ideal state or knows which variables are controllable, causal or reward-relevant. It instead learns from a proxy relationship. This proxy is the method's central scientific assumption.

## 2. Views and invariance

Let T1 and T2 be stochastic transformations and define two views X1=T1(X), X2=T2(X). A view-consistency objective tries to make f(X1) and f(X2) agree. The transformations encode an assumption: changes they introduce should usually not alter the feature of interest. Random crops presume some crop variation is nuisance; color jitter presumes certain color changes do not change the semantic label. These assumptions may be useful for object recognition but can be harmful for physical state estimation. Cropping can remove a velocity cue or an object boundary. Color changes may erase a visual marker that a robot uses for localization. A transformation pipeline is therefore part of the model's inductive bias, not generic preprocessing.

An ideal invariance can be described using an equivalence relation: x ~ x' when a downstream task requires treating x and x' as equivalent. In practice, augmentation defines only a proxy relation \u2248A. Training to collapse every pair from the same original input under \u2248A is justified only to the extent that \u2248A agrees with task relevance. Contrastive learning sharpens this problem by also sampling negatives, but negatives are likewise a proxy for distinctness.

## 3. Four forms of supervision generated by data

1. **Classification-style relation.** The model identifies which candidate matches an anchor. InfoNCE and CLIP use this pattern.
2. **Regression to another branch.** An online representation predicts a target representation. BYOL, SimSiam and JEPA-style methods share some mechanics but differ in target construction and task.
3. **Feature-statistic regularization.** Representations from paired views agree while batch statistics discourage low variance or redundant dimensions. Barlow Twins and VICReg use this pattern.
4. **Prediction of withheld content.** The input is corrupted or masked; the model predicts pixels, tokens, discrete codes or contextual features. MAE and BERT are canonical examples.

These are objective families, not exhaustive categories. One method can combine several.

## 4. Losses are easier to compare when the target is explicit

Each method can be specified through a contract:

- **Observed input:** single frame, multiple augmented views, text-image pair, or sequence.
- **Context available:** all tokens, visible tokens only, causal prefix only, or a separate view.
- **Target:** candidate index, teacher distribution, cluster assignment, pixel vector, discrete token, or teacher feature.
- **Similarity / prediction head:** cosine, dot product, learned projection, decoder, or classifier.
- **Anti-collapse mechanism:** negatives, stop-gradient/EMA and prediction asymmetry, variance/covariance terms, balanced assignment, or another explicit constraint.
- **Evaluation question:** what downstream information is linearly accessible, what is lost by masking, whether a target can be predicted, or whether the learned features transfer.

An objective comparison table should use these columns. It should not reduce the literature to a simplistic score ranking.

## 5. Cross-entropy from first principles

For classes k=1,...,K, logits a_k define softmax probabilities p_k=exp(a_k)/sum_j exp(a_j). If y is the correct class, one-hot cross-entropy is L=-log p_y. Differentiating gives dL/da_k=p_k-1[k=y]. The gradient therefore increases the correct logit and reduces the competing logits in proportion to the probability mass they currently receive. InfoNCE uses precisely this loss, but the “classes” are candidates in a minibatch or a queue, and the correct class is the designated positive view.

This reduction is pedagogically useful because it explains the mechanics before introducing an information-theoretic interpretation. No mutual-information story is needed to derive the loss or its gradient.

## 6. Collapse: distinguish objective, solution and training trajectory

Representation collapse usually means that distinct inputs map to the same or nearly the same feature. A constant encoder can satisfy simple invariance regression, because both views output the same vector. For this reason, view agreement alone is not enough. But there are three different claims:

- **Existence:** a collapsed parameter setting has low loss or is a stationary point.
- **Stability:** small perturbations toward non-collapsed features decay or grow under a specified training dynamics.
- **Observed outcome:** a complete implementation does or does not collapse under a particular architecture, optimizer, data distribution and seed.

Showing the first does not prove the second. Reporting the third does not establish a general theorem. For example, BYOL's moving target and predictor alter the update dynamics; SimSiam's stop-gradient changes the gradient field; VICReg directly penalizes zero per-dimension variance. Each explanation must name which kind of claim is being made.

## 7. Evaluation has its own target

A frozen linear probe fits a linear map from z to a labeled downstream target. Good performance means that some predictive information is linearly accessible from z under the tested data distribution. It does not show that the encoder is invertible, that every relevant variable is preserved, that the representation is robust to domain shift, or that a planner can use it. A nonlinear probe can extract more information but also makes stronger assumptions about probe capacity. Nearest-neighbor, fine-tuning and transfer evaluations answer different questions.

A world-model-oriented representation should be evaluated against the downstream contracts that motivate it: whether key state distinctions remain, whether future-relevant variables can be predicted, whether representations respond consistently to interventions, and whether action-conditioned dynamics are accurate. Standard SSL benchmarks often measure semantic recognition, which is an important but different target.
