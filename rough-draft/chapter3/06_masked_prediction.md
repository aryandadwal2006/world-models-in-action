# Masked prediction: targets matter more than the mask alone

## 1. A general formulation

Partition an input into visible tokens \(x_V\) and masked positions \(x_M\). An encoder processes the visible context, or a corrupted input, and a prediction head produces \(\hat y_M\) for the target at masked positions. The generic objective is

\[
L=\frac{1}{|M|}\sum_{i\in M}\ell(\hat y_i,y_i).
\]

This equation hides the most important decision: what is y_i? It can be a raw pixel patch, a discrete visual token, an original word, a replaced-token label, or a contextualized feature generated by a teacher. The mask specifies where information is hidden; the target specification determines what the model must recover.

## 2. MAE: reconstruct pixels with an asymmetric encoder-decoder

A masked autoencoder partitions an image into patches and randomly masks a large fraction of them. The encoder processes only visible patches, so masking reduces the expensive encoder's token count. A lightweight decoder receives encoded visible tokens and mask tokens, reconstructs the full patch sequence and predicts pixel values at masked patches. The loss is commonly mean-squared error over masked patches only.

The asymmetry is both a modeling and a compute decision: the encoder does not expend compute on masked tokens, while the decoder performs reconstruction. Random patch masks can be high-ratio because the visible patches still give a useful signal for learning visual structure. The target remains pixel-level, however, and MSE rewards the average of plausible pixel targets under uncertainty. A reconstructed image may look smooth yet not imply a feature sufficient for control.

The encoder is often the artifact reused for downstream tasks; the decoder may be discarded. The pretraining objective and downstream feature are therefore not the same object. This distinction should be stated whenever discussing MAE.

## 3. BEiT: predict discrete visual tokens

BEiT uses a visual tokenizer to map image patches into discrete code indices. The transformer sees a masked image and predicts the tokenizer's code at masked positions. The target is therefore a classification problem over learned codebook entries, not raw pixel regression. The codebook introduces a target vocabulary and its own inductive biases. If the tokenizer groups patches in a way useful to recognition, its codes may give a more semantic target; they can also preserve tokenizer artifacts and may not encode the information a physical predictor needs.

This is directly analogous in form to masked language modeling: the target is a discrete symbol rather than a continuous patch.

## 4. iBOT: masked patches and teacher-student targets

iBOT combines masked-image prediction with teacher-student self-distillation at the patch level. This makes it a useful example of overlapping taxonomy axes: its input construction is masked; its target comes through a teacher; output distributions are associated with learned prototypes. It should not be flattened into an exclusive “masked method” bucket.

## 5. BERT, GPT, and ELECTRA clarify the target choice

BERT masks a subset of input tokens and predicts the original tokens using bidirectional context. The original training recipe includes additional components, such as next-sentence prediction, that later work did not universally retain. GPT's autoregressive objective factorizes sequence likelihood by the chain rule:

\[
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t}).
\]

Its next-token loss uses the preceding context only. Both BERT and GPT are self-supervised pretraining methods, but only BERT's masked language-modeling task is a masked-token objective. GPT is causal language modeling.

ELECTRA corrupts selected tokens using a generator and trains a discriminator to detect whether each token was replaced. Instead of asking only the masked positions to predict token identity, the discriminator can receive a learning signal at many positions. It is a different self-supervised target, not another name for MLM.

These language models are valuable for a book-wide overview because they show how objective, context mask and target interact. In the actual chapter they should be short comparative vignettes, not a full treatment of language-model architectures.

## 6. data2vec: predict contextual features

data2vec predicts teacher representations computed from the full or less-corrupted input using a student that sees masked input. The targets are contextualized features rather than modality-specific labels such as a word, audio unit or raw pixel. The teacher is maintained separately and target features are aggregated in the prescribed recipe. This provides a general template across vision, speech and language.

A contextual target can carry global information unavailable from a local pixel or discrete unit, but this is still an assumption about the target's usefulness. Matching a teacher's feature does not automatically imply that the representation captures all causal state variables.

## 7. Comparing target spaces

| Method | Visible context | Prediction target | Loss family | Main design consequence |
|---|---|---|---|---|
| BERT | Bidirectional unmasked tokens | Original token IDs at masked positions | Cross-entropy | Requires recovery of lexical identities from both sides |
| GPT | Causal prefix | Next token | Cross-entropy | Learns ordered conditional sequence modeling |
| MAE | Visible image patches only in encoder | Pixel values for masked patches | Usually MSE | Strong image reconstruction signal and encoder compute savings |
| BEiT | Visible image tokens | Discrete visual-code IDs | Cross-entropy | Inherits the tokenizer's code distribution |
| iBOT | Masked image patches plus visible context | Teacher distributions, including patch-level targets | Distillation cross-entropy | Couples masking and self-distillation |
| ELECTRA | Corrupted token sequence | Original/replaced classification at token positions | Binary classification | Dense discriminator signal; generator defines corruptions |
| data2vec | Masked input | Contextualized teacher features | Feature regression | The teacher's representation defines what is retained |
