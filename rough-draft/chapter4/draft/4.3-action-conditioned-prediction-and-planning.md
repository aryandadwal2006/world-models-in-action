# 4.3 Action-conditioned prediction and planning

Passive video prediction is not yet a model of an agent's interventions. If a robot observes a cup moving across a table, the frames alone may not reveal whether the motion came from the robot, another person, gravity or an external disturbance. To predict the consequence of a candidate action, the model must receive action information and be trained on data that connect actions to subsequent observations.

An action-conditioned world model predicts a future representation from a history of observations and controls. A schematic form is
\[
\hat z_{t+1:t+H}
=
g_\phi(z_{t-L:t},a_{t:t+H-1},s_{t-L:t}),
\]
where \(z\) denotes visual features, \(a\) the action sequence, and \(s\) optional proprioceptive or end-effector state. The exact history length, action representation, conditioning mechanism and rollout target differ across implementations.

This extra input changes the identification problem. Passive pretraining can learn regularities in how the world usually evolves. Action-conditioned training must learn how the predicted future changes when the action changes. A model can be accurate on observed trajectories and still fail to answer counterfactual questions if the training data do not cover the relevant action-state combinations.

## From prediction to planning

Once a model can roll candidate actions forward in latent space, a planner can evaluate possible futures without decoding every pixel. Given a current latent state \(z_t\), candidate action sequence \(\mathbf a_{t:t+H-1}\)\), and goal representation \(z_g\), a basic objective is
\[
\mathbf a^*
=
\arg\min_{\mathbf a}
\mathcal C\left(
\hat z_{t+1:t+H}(\mathbf a),z_g
\right)
+
\lambda\mathcal R(\mathbf a).
\]
The first term measures predicted compatibility with the goal; the second can penalize action magnitude, infeasible controls or other constraints. This is a conceptual decomposition, not a universal objective used by every JEPA system.

A planner usually optimizes a sequence but executes only the first action or a short prefix. It then receives a new observation, updates its state estimate, and replans. This is model-predictive control. Replanning limits the period during which the system relies on an open-loop prediction, but does not remove errors in the learned model or guarantee safety.

Several design choices interact:

- **Horizon:** a longer rollout gives the planner more foresight but allows prediction errors to compound.
- **Action representation:** low-level motor commands, end-effector deltas and temporally extended actions define different control problems.
- **Proprioception:** robot state may disambiguate visually similar scenes or indicate the current configuration of the arm.
- **Predictor architecture:** temporal context, action conditioning and normalization determine how the model uses its inputs.
- **Planner:** random shooting, the cross-entropy method, gradient optimization and other optimizers have different assumptions and failure modes.
- **Goal and cost:** latent distance is a proxy for task success. It may ignore collisions, force constraints, hidden state or irreversible outcomes.

A strong planning result is therefore a result about a complete system: encoder, predictive model, action data, planner, objective, environment and feedback loop.

## V-JEPA 2-AC as a staged example

V-JEPA 2-AC makes the division between representation and dynamics explicit. The V-JEPA 2 visual encoder is first trained with action-free video and image data. The second stage freezes the visual encoder and trains an action-conditioned predictor using robot trajectories. The predictor uses past frame features, robot actions and end-effector states to estimate future frame features.

The post-training data are much smaller than the passive pretraining corpus. The V-JEPA 2 paper reports less than 62 hours of unlabeled robot video from DROID for the action-conditioned stage. The system is deployed on Franka arms in two laboratories and plans toward image goals. Its zero-shot claim is tied to the evaluated deployment environments and tasks; the model still uses robot interaction data during post-training.

This staged strategy separates two forms of knowledge. Large-scale passive video pretraining builds broad visual representations. Robot trajectories add information about the relation between control variables and future observations. The action-conditioned predictor is not obtained simply by relabelling an action-free predictor as a world model.

## The broader JEPA-WM design space

The JEPA-WMs study by Terver and colleagues (2025/2026) investigates which model and planning choices contribute to physical planning performance. It examines visual encoders, predictor architecture and depth, the number of rollout steps used during training, context length, proprioception, model scaling, and planning optimizers. The paper evaluates simulated environments and real-robot data, and combines its ablations into a proposed model that outperforms the DINO-WM and V-JEPA 2-AC baselines on the reported navigation and manipulation evaluations.

This is valuable because it shifts attention from a single pretraining objective to the entire model-planner interface. Multi-step rollout training is intended to improve predictions beyond the immediate next step. Proprioception can help the predictor distinguish states that appear similar visually. The choice of planner determines how effectively the learned model can be searched. The results remain tied to the paper's experimental tasks and baselines.

The official JEPA-WMs repository contains code, datasets and checkpoints. Its license is CC BY-NC 4.0, so code and model artifacts should not be copied into a commercial textbook. The chapter can describe the architecture and reported experiments in its own words, with attribution, without reproducing restricted code.

## Energy-based prediction and planning

Energy-based models provide a complementary way to score compatibility. An energy function (E(x,y)) assigns a scalar to a pair or configuration. Lower energy means the configuration is preferred under the model's learned scoring convention. An energy function is not automatically a normalized probability distribution. To obtain a Gibbs density, one would need a partition function:
\[
p(y\mid x)
=
\frac{\exp[-E(x,y)]}{Z(x)},
\qquad
Z(x)=\int \exp[-E(x,y')]\,dy'.
\]
For complex continuous spaces, computing (Z\(x\)) can be intractable. Many energy-based systems therefore use the energy as a score or objective without explicitly evaluating a normalized density.

In a predictive world model, energy can score whether a proposed future representation is compatible with the context or whether a trajectory satisfies a desired constraint. In an agent architecture, a cost can instead express a task objective or discomfort. These uses are related but not identical. A prediction loss measures mismatch to a training target; an energy scores compatibility; a task cost ranks futures according to goals. The same scalar notation should not hide these different semantics.

EB-JEPA is an official Meta FAIR library and tutorial for JEPA-style representation learning, prediction and planning. Its examples include image JEPA, video JEPA and action-conditioned video JEPA for planning in a Two Rooms environment. The repository is Apache-licensed. It is a useful executable reference, but it should be described as a library and collection of examples, not casually equated with a separate foundational theorem about energy-based learning.
