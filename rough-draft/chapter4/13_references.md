## Bibliographic cautions

- Use the latest paper version available at manuscript freeze, but cite the version that supports the precise claim.
- V-JEPA 2.1's paper and repository were visible as of 2026-10-31; record version/date if using benchmark numbers.
- V-JEPA 2-AC is a stage/model in the V-JEPA 2 work, not a separate paper title in the same way as I-JEPA.
- EB-JEPA is an official library/examples repository. It should not be presented as a single canonical primary paper without an associated paper citation.
- Var-JEPA (Gögl and Yau) and VJEPA (Huang) are distinct ICML 2026 papers. Do not merge them.
- A Path Towards Autonomous Machine Intelligence is a position paper.
